# 能量与粒子表现

`runtime/rendering/realistic_effects.gd`复用旧已签名工厂的尺寸、粒子数、过程参数、寿命、碰撞边界和挂点，只替换显示材质及粒子的绘制网格。战斗命中、伤害和数值仍由原业务服务/数据库决定。

四个shader分别绘制柔边能量体、朝向相机的软粒子、局部护盾涟漪和透明中心的门效。unshaded路径将辐射写入ALBEDO；材质时钟接入原节点的age/visual_time，GPU粒子同步暂停。特效强度实时更新已存在和随后生成的反馈，0隐藏附加反馈但保留战斗实体与声音。

原生验收同时检查可见像素、暂停/恢复、过期/归属清理、预算、常驻门效0→开启、状态/RNG不变；结果与边界见[69](../../../doc/69-交互一致性与材质表现优化.md)。
