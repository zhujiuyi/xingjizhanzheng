# navigation-v3

本项目独立的表现与导航定义包。`data/navigation_v3.db` 从 `database/navigation_v3.sql` 生成：3 个雷达显示范围、10 个星区的天体名称、场景位置、表面色与随机种子。进度、探测上限、停靠和传送资格继续取当前远征的原内容 SQLite，未复制玩法平衡值。

局部回波只显示当前档案探测范围以内的对象。远景行星属于已知航向，位于雷达周缘，带独立图形和高度标记；它们没有碰撞或登陆功能，场景压缩距离不作为物理行星距离展示，也不会获得 F 交互资格。

行星使用原创生成的等距经纬表面贴图与项目原生 PBR shader；星空使用原创暗色星云全景，按星区旋转天球。来源在 `sources.json`，两个生成请求都没有使用 EVE 或其他游戏图像。请求强调经度包裹，不宣称严格数学无缝。名称、参数仍由只读 SQLite 管理；两个贴图、shader、数据库四项资源按 manifest 校验并原样打包。

重建入口：工作区根目录执行 `python3.14 jiaoben/build_navigation_v3.py`。仅重建本包生成数据库，不能指向玩家存档。验证见 `jiaoben/tests/navigation_v3.gd`、文档31与交付记录26。
