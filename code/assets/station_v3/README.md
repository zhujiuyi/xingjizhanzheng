# 空间站工业外观 v3

独立的原创表现包，保持旧 `station_anchor.tscn`、原 79 个资产及核心数据库字节不变。`station_visual_adapter.gd` 只替换旧站 `VisualRoot/Model`；`StaticBody3D`、碰撞形状、交互锚点、实体 ID、世界位置和停靠规则继续由原系统管理。

新外观为分段装甲环、开放承重桁架、中央反应堆与服务芯、非对称炼化/货运/居住模块、凹入泊位、导向灯与维护机械。粗糙钢材、深色凹槽与小窗光建立工业尺度，不使用旧亮银三层圆盘。泊位在 Godot 的 +Z 方向。

Blender 中以米为单位制作，导出 glTF 2.0/GLB、Y 向上。整个外观在原 440×230×440 米碰撞盒内；泊位负空间仅是视觉结构，原盒没有可穿越的船坞开口。停靠采用原靠近后交互规则。该包不提供新的数值或资产碰撞。

正式运行文件为 GLB、空间着色器、几何元数据和 manifest；`source/` 内保存可编辑 Blender 源文件并用 `.gdignore` 排除运行导入。建模与 manifest 构建脚本在 `jiaoben/art/`，临时截图只在 `jiaoben/tmp/station-v3/`。

原生着色器复用项目已有原创 `interface_v2/metal_albedo.png`，采用三平面采样，保持装甲与涂层的粗糙度、保留两种小面积灯光材质。8 个共享材质面减少绘制开销；单级静态模型不含动画、骨骼或物理节点。源三角数、导入边界、材质与原资源摘要由 `test_station_v3.gd` 检查；最终游戏和客户端验证由集成阶段完成。

来源：项目自制几何、Blender 脚本与 Godot shader，无第三方模型、付费素材、截图裁片或第三方贴图。EVE 的工业空间站概念仅作功能、结构和尺度参照，本模型不是其模型重建。离线 Blender 渲染用于轮廓审核，不作为原生 Godot 渲染或交付验收证明。

独立验收：最终 headless 与 Metal/CoreAudio 原生测试均 114/114 PASS；114 项包括原 79 资产与核心 catalog 摘要、实际导入尺寸/材质、碰撞/交互锚点/世界姿态不变、幂等与错误对象拒绝。最终原生预览在 1440×900 下保存正面和三分之四角截图，采用 `sector_anchor` 相同的 key2.0/ambient0.7/fill0.65/filmic 与项目星空；各引擎日志未见错误、警告或泄漏。最终游戏窗口和客户端集成仍由主开发阶段验收。
