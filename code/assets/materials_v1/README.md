# 分类表面表现包

仅新增运行时材质、确定性微结构数据和视觉网格适配器；原 GLB、wrapper、碰撞、挂点、位置、旧资源清单与存档资产身份保持不变。

`micro_surface.png` 由项目自制 `jiaoben/art/build_material_micro.py` 生成：256×256周期性数学纹理，R为微高度、G为粗糙变化、B为加工细纹；无烘焙光照、图案铆钉或外部素材。shader使用线性数据、mipmap三平面采样和低幅导数法线，不修改顶点或时间。

岩体另用`rock_strata.png`低频数据，周期仅1–5，按0.025次/米采样：R为岩层宏观起伏、G为有限矿化区域、B为细脉场。矿化只进入少量区域，局部金属混合目标0.12、粗糙度目标0.80，不用加工微纹理制造全表面的金属蚀刻亮点。导数法线乘模型缩放，保证缩小展示舰与真实舰使用相同相对表面尺度。

裸金属、钢板、涂装、凹槽、陶瓷、岩石、金属矿脉、晶体、玻璃、衣料、橡胶与皮肤拥有独立金属度/粗糙度响应。玻璃是暗色不透明介质镜面，不假造缺失的舱内结构；晶体仍沿用原色相，发光缩为原强度的18%。独立灯具、终端屏幕及战斗特效保留其原业务/动态shader通道。

程序盒以44三角真实内切倒角副本替换；探索遮挡物使用128三角确定性内缩副本，六轴极值沿用原可视AABB。替换仅发生在显式目标类别，不修改球形碰撞、天体或能量球。几何缓存不包含场景状态与材质。

八种矿体的母岩使用2048三角确定性不规则网格，以实际变形面的梯度计算连续法线，只混入12%面法线；避免初版512三角的大三角面观感。岩粒只调制漫反射与微高度，不制造金属亮点。非晶体矿石将旧突起条块合并成贴近岩面的shader矿化细纹/斑块；晶体保留原簇几何。非晶体保持整块矿体聚合AABB，允许旧子网格包围及表面数变化；原来源、材质、子节点变换和合并关系保存为表现metadata。旧矿脉节点不再保留隐藏网格，不用不可见旧几何撑住包围测试。所有碰撞和交互锚点保持。

新机库子类保留已签名机库代码。`hangar_reflection.res`由`jiaoben/art/bake_hangar_reflection.gd`在原生渲染器中捕捉真实静态机库的六面256×256图，并生成mipmap；捕捉层为18，动态舰船、角色与服务无人机不进入捕获。中/高画质使用该Cubemap的Sky反射，低画质使用128分辨率的中性ProceduralSkyMaterial，并关闭SSAO/glow。实际背景继续使用BG_COLOR，不修改数据库恒星光照。此图是固定房间的LDR环境反射，不提供动态对象反射或实时视差修正。

初版使用实时ReflectionProbe。独立原生base/low/high对照确认仅启用probe的high退出泄漏7个Texture RID，与锁定引擎的[上游问题122498](https://github.com/godotengine/godot/issues/122498)一致；改为静态捕捉后原生退出无此告警，不屏蔽日志或手动释放引擎私有RID。

参数属于固定表现资产。原生渲染与资源身份检查、已修问题及实际发行验收记录在[69](../../../doc/69-交互一致性与材质表现优化.md)；manifest只登记身份，不单独代表验收通过。
