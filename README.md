# 星际战舰

v0.16.0文明扩展：54个星系、三个各有12个星系的文明、18个中立星系；核心站入籍、单一效忠与改换、矿物捐献、八级声望爵位、九型专属中高级舰及NPC舰队征服任务。完整玩法与存档升级见[文明声望与星域战争](doc/49-文明声望与星域战争.md)，最终构建和验收以[交付记录](doc/26-开发阶段与交付记录.md)为准。

一款以星际探索、采矿、战斗与不同类型战舰操作为核心的 3D 单人游戏。技术栈为 Godot 4 + typed GDScript + Forward+ + Blender + SQLite，保留联机接口。v0.8.4将市场、舰队、仓储、配装、工业、任务及研究/设施统一为图片列表，展示真实描述、单位、数量、报价、库存和操作。九类舰体使用正式工业模型缩略图，物品使用原创图示；数量更新保留列表位置，小窗口支持纵横滚动及键盘焦点。详见[业务列表方案](doc/37-资产与业务列表界面.md)。

v0.15.1修正真实跃迁出发场景不退离和正常背景虚化弱的问题：源站/门/矿快速退离，精确舰体轮廓保持清晰，周围天空散焦和少量柔和尾流按实际像素适配；原航程、数值和存档定义保持，见[47](doc/47-跃迁离场与真实背景虚化修正.md)。v0.15.0真实AU航路与独立任务筛选见[46](doc/46-星系尺度与跃迁体验.md)。实际测试与交付身份以[交付记录](doc/26-开发阶段与交付记录.md)最新章节为准，下面旧版本包链接属于历史记录。武器、舰种和光影规格见[45](doc/45-光影与武器舰种平衡.md)。

保留原十星系教学与剧情航路、39种模块、3D机库/NPC、本星系跃迁与三维导航、独立自动开火、有限矿点及SQLite完整存读档。操舰、[姿态回正](doc/36-舰船姿态回正与相机基准.md)、[航行HUD](doc/35-航行HUD布局与通知去重.md)、[矿点情报](doc/34-教学采矿保障与矿点情报.md)及[导航交互](doc/33-指令式操舰与运动重影修正.md)沿用已验收规则。

历史macOS客户端已在Apple Silicon Mac实测；近期版本在Windows x64原生运行验证。各版本交付路径、构建身份和验证边界见[交付记录](doc/26-开发阶段与交付记录.md)，启动方式见[客户端说明](doc/28-客户端使用与交付说明.md)。构建包不入Git；Windows本机用`jiaoben/build_client.py --platform windows`构建，再按交付检查验收实际包。

历史交付（v0.8.4）：[Mac客户端](code/dist/0.8.4-927e9d3c-20261004-000222/mac/星际战舰.app) · [Mac压缩包](code/dist/0.8.4-927e9d3c-20261004-000222/星际战舰-macOS.zip) · [Windows压缩包](code/dist/0.8.4-927e9d3c-20261004-000222/星际战舰-Windows-x64.zip)。实际Mac包已通过6项数据库与78项表现检查、14张截图及248项资源校验；Windows原生运行未验收。先退出旧客户端，再打开新版。
