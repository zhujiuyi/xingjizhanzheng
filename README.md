# 星际战舰

当前正式版本 **v0.32.0**。本轮34项单机技术目标已完成，真人试玩另行安排。

[启动Windows客户端](code/dist/0.32.0-ecd1f6b4-20261014-042733/windows/XingjiZhanjian.exe) · [完整Windows压缩包](code/dist/0.32.0-ecd1f6b4-20261014-042733/星际战舰-Windows-x64.zip)

游戏包含54个星系、三个文明、18型舰船及梯队武器；支持探索、采矿、贸易、研究、制造、无人机、自有编队与船员、分段远征和边疆战争/建设。NPC战役舰队经真实地点与航门行军，保留原舰身份、伤损和物资；成长面板提供简短的目标、缺口与实际导航入口。

已有世界通过备份和新版规则分支安全升级，保留资产及旧手动档。个人存档位于Windows的 `%APPDATA%\Godot\app_userdata\星际战舰\database\progress.db`。
