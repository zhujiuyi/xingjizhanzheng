# 星际战舰

一款以星际探索、采矿、战斗与不同类型战舰操作为核心的 3D 游戏。技术栈为 Godot 4 + typed GDScript + Forward+ + Blender + SQLite。当前 v0.8.0 使用常驻光标、左键短击选择/长按观察、WS沿视角推进、AD转弯及总览双击接近；观察不取消导航，相机/模型/标注统一渲染姿态。在完整单人内容上保留本星系跃迁、物理接近、三维环绕、自动接近停靠、场景点击选中、自动开火辅助、分类总览、真实设备栏和十星系图形星图。航行采用暗色透明面板与金色重点，保留居中的工业舰船、雷达、淡白虚线和单层目标标注；空间站提供3D机库与NPC。十星系、九类舰船、三十种模块、任务、工业市场、研究基地与SQLite完整存读档继续可用，保留联机接口。操作与验证边界见 [操舰与运动修正](doc/33-指令式操舰与运动重影修正.md)，既有参考见 [曦航对标记录](doc/32-曦航对标与导航交互改进.md)。

macOS 客户端已在 Apple Silicon Mac 实际启动并验证存读档；Windows x64 包已成功导出，原生 Windows 运行尚未验证。交付路径、构建身份与验证边界见 [交付记录](doc/26-开发阶段与交付记录.md)，启动方式和操作见 [客户端说明](doc/28-客户端使用与交付说明.md)。构建包不入 Git；可用 `jiaoben/build_client.py --platform all --publish` 重建。
