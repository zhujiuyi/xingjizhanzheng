# 星际战舰

一款以星际探索、采矿、战斗与不同类型战舰操作为核心的 3D 游戏。技术栈为 Godot 4 + typed GDScript + Forward+ + Blender + SQLite。v0.8.3修正A/D后残留倾斜，松键后按舰船转速平滑回正，保留上下航向与惯性速度；跟随镜头不继承旧滚转，Q/E按住仍可主动滚转。继续使用v0.8.2的顶部菜单、紧凑通知、加长总览及底部同排舰况/设备，以及v0.8.1有限教学矿量保障、剩余量和再生情报。光标常驻、左键短击选择/长按观察、WS沿视角推进、AD转弯、总览双击接近，观察不取消导航。完整单人内容保留本星系跃迁、接近/环绕/停靠、独立自动开火、分类总览、真实设备栏、十星系星图和3D机库/NPC；九类舰船、三十种模块、任务、工业市场、研究基地与SQLite完整存读档继续可用，保留联机接口。姿态规则见 [舰船姿态回正](doc/36-舰船姿态回正与相机基准.md)，布局见 [航行HUD方案](doc/35-航行HUD布局与通知去重.md)，采矿见 [教学保障与矿点情报](doc/34-教学采矿保障与矿点情报.md)，操舰与运动表现见 [33](doc/33-指令式操舰与运动重影修正.md)，参考记录见 [32](doc/32-曦航对标与导航交互改进.md)。

macOS 客户端已在 Apple Silicon Mac 实际启动并验证存读档；Windows x64 包已成功导出，原生 Windows 运行尚未验证。交付路径、构建身份与验证边界见 [交付记录](doc/26-开发阶段与交付记录.md)，启动方式和操作见 [客户端说明](doc/28-客户端使用与交付说明.md)。构建包不入 Git；可用 `jiaoben/build_client.py --platform all --publish` 重建。
