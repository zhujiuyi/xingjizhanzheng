# 星际战舰

《星际战舰》是一款以星域探索、舰船配装和文明成长为核心的单人 3D 太空沙盒游戏，使用 Godot 4、GDScript 和 SQLite 开发。

玩家从中立星系起步，通过任务、探索、采矿和贸易积累资产，研究并制造舰船与装备，建立自己的编队；也可以加入文明，提升声望与爵位，参与远征、边疆战争和殖民地建设。当前游戏采用离线单人模式，在线多人玩法的规划见[后续路线图](doc/50-下一阶段玩法与在线化路线图.md)。

## 主要玩法

- **星域探索**：穿行于三大文明、中立和争夺星域，调查异常、遗迹与矿带，完成教学、主线和区域任务。
- **航行与战斗**：在局部空间操舰、交战和停靠，使用星系内跃迁与跨星系航门旅行；不同武器具有不同射程、弹道和命中表现。
- **舰船配装**：根据舰种、槽位和能源预算搭配武器、防御及功能模块，通过科技研究解锁装备梯队和文明专属舰船。
- **采集与工业**：采矿、打捞、加工、研究和制造，在空间站市场交易，承担物资运输与补给任务。
- **舰队指挥**：招募船员、部署自有僚舰或雇佣支援，管理攻击、维修与侦察无人机，指挥编队协同作战。
- **远征与边疆**：完成文明考核，随 NPC 舰队跨星系行军，参与侦察、护送、攻占、重建和殖民工程。

## 开始游戏

Windows x64 客户端可直接运行，无需安装 Godot、Python 或数据库服务。客户端包的位置和校验信息见[交付记录](doc/26-开发阶段与交付记录.md)中的最新正式交付章节；本地正式包保存在 `code/dist/<构建编号>/`，构建产物不随源码提交。

1. 完整解压客户端包，运行 `windows/XingjiZhanjian.exe`。保留同目录下的 `.pck`、SQLite `.dll` 及随包文件。
2. 首次进入选择“新建远征”，按教学任务熟悉出航、采集、战斗和返航。
3. 已有进度可通过“继续航行”或“读取存档”恢复。

详细操作、快捷键和各系统入口见[客户端使用说明](doc/28-客户端使用与交付说明.md)。

Windows 存档目录为 `%APPDATA%\Godot\app_userdata\星际战舰\database\`，主进度文件为 `progress.db`。退出游戏后可备份整个存档目录。

## 从源码运行

工程使用 **Godot 4.7.2 标准版、GDScript 和 Forward+ 渲染器**，依赖版本以[工具链锁文件](code/toolchain.lock.toml)为准。Godot SQLite 扩展及运行资源已随仓库提供。

克隆仓库后，在项目根目录的 PowerShell 中执行：

```powershell
# 将路径替换为本机安装的 Godot 4.7.2 标准版可执行文件。
$env:GODOT_BIN = 'D:/DevTools/Godot/4.7.2/Godot_v4.7.2-stable_win64_console.exe'
& $env:GODOT_BIN --editor --path ./code
```

等待首次资源导入完成后，在编辑器中按 **F5** 运行项目。也可以通过 Godot 项目管理器导入 `code/project.godot` 后运行。

工具安装、macOS 环境和渲染检查见[开发环境](doc/02-开发环境.md)。Blender 用于修改和重新生成模型；使用仓库内已有运行资源时无需安装。

## 构建客户端

构建 Windows 客户端还需 **Python 3.11+**、Git for Windows（确保 `git` 和 `sh` 命令可用）以及与引擎匹配的 Godot 导出模板。在已设置 `GODOT_BIN` 的同一 PowerShell 窗口中执行：

```powershell
$env:PYTHONUTF8 = '1'
$env:PYTHONIOENCODING = 'utf-8'
py jiaoben/build_client.py --platform windows
```

输出位于 `jiaoben/tmp/delivery/<构建编号>/`，包含客户端、压缩包和构建清单；日志位于 `jiaoben/logs/`。该命令执行资源校验和导出，正式交付还需完成对应的客户端验收。其它平台和检查入口见[开发环境](doc/02-开发环境.md)及[脚本目录说明](jiaoben/README.md)。
