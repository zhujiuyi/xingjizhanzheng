# 星际战舰

一款以星际探索、采矿、战斗与不同类型战舰操作为核心的 3D 单人游戏。技术栈为 Godot 4 + typed GDScript + Forward+ + Blender + SQLite，保留联机接口。v0.8.4将市场、舰队、仓储、配装、工业、任务及研究/设施统一为图片列表，展示真实描述、单位、数量、报价、库存和操作。九类舰体使用正式工业模型缩略图，物品使用原创图示；数量更新保留列表位置，小窗口支持纵横滚动及键盘焦点。详见[业务列表方案](doc/37-资产与业务列表界面.md)。

v0.14.0补充恒星方向光/阴影、分类弹道与命中表现、舰种挂载权限及18种攻击模块；新增三级中轨/重轨/无人机机库，旧世界备份后受审分支升级，既有资产/任务和旧手动档保留。实际测试与交付身份以[交付记录](doc/26-开发阶段与交付记录.md)最新章节为准，下面的旧版本包链接属于历史记录。武器、舰种、旧档及特效规格见[45](doc/45-光影与武器舰种平衡.md)。

继续保留十星系、三十种模块、3D机库/NPC、本星系跃迁与三维导航、独立自动开火、有限矿点及SQLite完整存读档。操舰、[姿态回正](doc/36-舰船姿态回正与相机基准.md)、[航行HUD](doc/35-航行HUD布局与通知去重.md)、[矿点情报](doc/34-教学采矿保障与矿点情报.md)及[导航交互](doc/33-指令式操舰与运动重影修正.md)沿用已验收规则。

macOS 客户端已在 Apple Silicon Mac 实际启动并验证存读档；Windows x64 包已成功导出，原生 Windows 运行尚未验证。交付路径、构建身份与验证边界见 [交付记录](doc/26-开发阶段与交付记录.md)，启动方式和操作见 [客户端说明](doc/28-客户端使用与交付说明.md)。构建包不入 Git；可用 `jiaoben/build_client.py --platform all --publish` 重建。
