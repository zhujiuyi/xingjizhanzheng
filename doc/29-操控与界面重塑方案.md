# 操控与界面重塑方案

状态：第二版界面已实现，并完成本轮原生渲染和业务回归；按实际试玩意见重塑默认站内、飞行仪表、首页及服务页。以下证据属于本轮新代码，不沿用第一版 PASS。

## 目标与分工

界面从文字列表与服务菜单改为工业科幻游戏工作台：深碳灰金属、细噪声、切角框架，以冰蓝提示常态，以琥珀提示重要操作与风险。新增界面与机库资源分别放 `code/assets/interface_v2/`、`code/assets/hangar_v2/`，不改旧版79项资源原始字节；表现包独立清单与客户端验证已接入。

- 飞行：中央固定准星；底部中央舰况仪表整合速度、护盾、装甲、结构、电容与热量；左侧目标/作业说明，右侧目标模块，底部紧凑导航。
- 站内：默认展示可见的 3D 机库；左侧四类 NPC 服务入口，右侧驾驶舰状况，底部出港。服务页是独立工作台，不再让默认站内界面遮住机库。
- 业务：固定侧栏、标题、资产位置与余额；材料和需求置于卡片，按钮区分主要/次要/锁定状态；任务、交易、制造、存读档与失败反馈均保留现有业务规则。
- 首页：独立标题背景、继续/新远征/档案/设置/退出；中文字体维持系统回退。

UI 仅由 `ui.gd`、`ui_theme.gd` 和 UI shader/SVG 实现；`requested` 信号和 `bind`、`show_page`、`notify` 等公共接口保持。机库、视角、鼠标转向、数据库与玩法实现分别由整合代理处理，UI 不写 gameplay state。

同一 Theme 管理字体、切角底板、控件、焦点和禁用状态；UI 不用几套独立颜色覆盖业务页。底板为原创九宫格 SVG，金属 PNG 以 shader 强度 0.12 进行低对比静态调制，并添加细噪声与拉丝；生成金属原图不被标为严格数学无缝。NPC 的 1254×1254 图集用四个 627×627 AtlasTexture 区域加载，文字由 Godot 原生控件绘制。

## 操控、焦点与缩放

- 飞行鼠标默认捕获，相对移动产生有限角度请求，按数据库转速上限逐步完成；鼠标停止后可能有短暂剩余转角，清空后不再转向，不以光标偏离中心持续转舰。右键自由观察，松开回正；Alt 切换界面操作，菜单、停靠、失焦释放鼠标并清空请求；关闭菜单由主程序恢复捕获。UI 设置使用“鼠标灵敏度”，读取本机已保存偏好，打开设置不发送默认值覆盖数据库。
- Esc 层级由主程序统一：站内 → 暂停；业务 → 机库或飞行；暂停 → 机库或飞行；飞行 → 暂停。设置返回按钮记住进入前页面，世界内设置的Esc进入暂停。战术视角固定仰角，仅支持水平环绕及滚轮缩放；跟随与舰首支持自由观察俯仰。
- 每页建立可用默认焦点，Tab/Shift+Tab 和上下方向邻接闭环；锁定按钮不纳入可用链。保存等待取消按钮纳入菜单焦点链。鼠标悬停反馈 0.09 秒、页面显现 0.14 秒，使用 ease-out，切页先终止旧动画。
- HUD 锚定屏幕边缘和底部中心；主要内容使用 VBox/HBox/Grid/ScrollContainer。安全边距为逻辑像素 14–22；窄布局隐藏工作台侧栏，改用页选择器，卡片单列；宽布局按可用宽度双列。实际窗口缩放会重排所有既有卡片组，不要求重新打开页面。
- 200% 字体/UI 缩放下保留舰况数字和防御弧，缩短辅助文字，站内右侧详情折叠以保证中央可见；服务列表和业务内容允许滚动，不把关键出港、返回和取消操作放在视口外。

本轮保持主程序调用的 tick/read adapter：界面每 0.25 秒刷新一次状态，舰况签名未变则不重复更新仪表，目标按钮复用而不循环重建。没有把这一兼容实现声称为完全事件驱动架构；业务命令仍只发 requested 信号，UI 不写游戏状态。

## 本轮验证与证据

运行 Godot 4.7.2 原生 Metal / Forward+；测试使用独立临时进度库。覆盖首页、实际整合机库、舰队、仓库、配装、市场、工业、任务、科研、星图、暂停、设置和飞行；尺寸 1280×720、1440×900，UI 缩放 100%/200%。扫描和 NPC 组合为明确视觉夹具，不写正式进度，不当作实战或任务完成证明。

- [UI 原生布局检查](../jiaoben/tests/ui_visual_v2.gd)：[本轮日志](../jiaoben/logs/ui-visual-v2.log) 最终 RESULT 为 75/75 PASS、42 张截图，未见 ERROR/WARNING；含实际 main 机库整合，无 PREVIEW 临时挂接分支。新增检查覆盖首页高缩放、实时卡片重排和保存取消焦点链。
- [业务回归](../jiaoben/tests/ui_usability.gd)：[headless](../jiaoben/logs/ui-usability-v2-headless.log) 200/200 PASS，[native](../jiaoben/logs/ui-usability-v2-native.log) 201/201 PASS。验证真实报价、数量上限、开关意图、任务顺序、目标条、保存取消、中文字符与原生鼠标阻塞。
- 编辑器注册日志 [ui-v2-editor.log](../jiaoben/logs/ui-v2-editor.log) 未见 UI parse 错误。本轮增加的新全局类必须先导入；并行整合时的旧 class cache 启动失败不计为通过。

整合后新增 [镜头与操控检查](../jiaoben/tests/camera_controls_v2.gd)，原生Metal 196/196 PASS。覆盖九舰×1280×720/1440×900/1920×1080三种分辨率、移动与转向居中、舰首精确锚点、自由观察回正、30/60/144Hz相对角度预算、最小/最大缩放极点、平滑途中的up共线回退、停靠暂停/星图按钮返回和再次出港首帧定位。数值刺激为测试夹具，转速由正式SQLite库读取。发现并修复了近距离俯仰翻转、停靠继续按钮丢失服务页及再次出港沿用旧相机位置三项边界问题。
