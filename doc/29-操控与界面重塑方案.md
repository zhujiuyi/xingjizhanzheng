# 操控与界面重塑方案

状态：v0.6字体、第三版Theme、条件交互、局部导航和工业美术已完成源码、本机整机原生回归及实际Mac Release固定诊断。Windows x64导出与组件检查通过，Windows原生运行未验收；额外人工操作复查尚未完成。各阶段证据分开记录。

## 目标与分工

界面从文字列表与服务菜单改为工业科幻游戏工作台：深碳灰玻璃、精细工程线框、焦点括角和功能刻度，以冰蓝提示常态，以琥珀提示重要操作与风险。首页主视觉及NPC图集仍用 `code/assets/interface_v2/`，机库用 `code/assets/hangar_v2/`；字体、控件框架与玻璃shader在 `code/assets/interface_v3/` 独立管理。不改旧版79项资源原始字节，不复制参考游戏的UI或美术资源。

本轮空间背景及外部结构同时采用独立 `navigation-v3`、`station-v3` 和新工业舰船表现包：前者提供原创星云/地貌与导航定义，空间站和舰船只替换视觉模型。空间站headless/原生各114项、全舰契约各410项及本机整机原生回归已通过；当前Mac Release包的原始资源校验和固定诊断也已通过。范围和来源见31。

- 飞行：中央固定准星；底部中央舰况仪表整合速度、护盾、装甲、结构、电容与热量；左侧目标/作业说明，右侧目标模块，底部紧凑导航。
- 站内：默认展示可见的 3D 机库；左侧四类 NPC 服务入口，右侧驾驶舰状况，底部出港。服务页是独立工作台，不再让默认站内界面遮住机库。
- 业务：固定侧栏、标题、资产位置与余额；材料和需求置于卡片，按钮区分主要/次要/锁定状态；任务、交易、制造、存读档与失败反馈均保留现有业务规则。
- 首页：独立标题背景、继续/新远征/档案/设置/退出；界面和3D人员标签共享随包提供的中文字体。

UI 仅由 `ui.gd`、`ui_theme.gd` 和 UI shader/SVG 实现；`requested` 信号和 `bind`、`show_page`、`notify` 等公共接口保持。机库、视角、鼠标转向、数据库与玩法实现分别由整合代理处理，UI 不写 gameplay state。

### 统一中文字体

采用官方 [Noto Sans CJK SC Regular](https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese) 2.004，固定仓库提交 `f8d157532fbfaeda587e826d4cd5b21a49186f7c`，未经裁剪或修改。OTF、原始 [OFL 1.1许可](../code/assets/interface_v3/LICENSE-OFL.txt) 与版权信息随客户端分发；没有复制PingFang或微软雅黑文件。

`XJUITheme.font()` 返回同一个预加载FontFile，禁止系统回退；Theme控件与四名机库人员Label3D共用该资源。保持 `font/plate/flat/button_style/create/texture/decorate` API，增加 `focus_style`。第三版清单登记9项原始资源，字体、SVG和shader的来源、版本、摘要及分发边界见 [资源说明](../code/assets/interface_v3/README.md)。装饰缺字改为矢量小块或ASCII符号，不靠另一字体遮掩。

## 操控、焦点与缩放

- 飞行鼠标默认捕获，相对移动产生角度请求，按数据库转速上限完成；超预算转角只保留一个额外物理步，最后一次输入后最多两个物理步停止请求（默认60Hz约33ms），避免大舰停手后持续追赶积压角度。低于转速上限的连续运动保持时间一致，持续快速移动按舰种转速限幅。右键自由观察，松开回正；Alt 切换界面操作，菜单、停靠、失焦释放鼠标并清空请求；关闭菜单由主程序恢复捕获。UI 设置使用“鼠标灵敏度”，读取本机已保存偏好，打开设置不发送默认值覆盖数据库。
- Esc 层级由主程序统一：站内 → 暂停；业务 → 机库或飞行；暂停 → 机库或飞行；飞行 → 暂停。设置返回按钮记住进入前页面，世界内设置的Esc进入暂停。战术视角固定仰角，仅支持水平环绕及滚轮缩放；跟随与舰首支持自由观察俯仰。
- 每页建立可用默认焦点，Tab/Shift+Tab 和上下方向邻接闭环；锁定按钮不纳入可用链。保存等待取消按钮纳入菜单焦点链。鼠标悬停反馈 0.09 秒、页面显现 0.14 秒，使用 ease-out，切页先终止旧动画。
- NPC 肖像和右侧服务入口是两个独立、可键盘聚焦的按钮。`NpcPortrait0..3` 分别发送 `hangar_focus` 的 operations/supplies/industry/research 请求；`HangarOverview` 发送空目标返回总览。UI 只发送既有 requested 信号，不移动镜头或写游戏状态。卡片保持 87 逻辑像素高，原四个 AtlasTexture 及服务页返回、出港规则保持；高缩放下入口随服务列表滚动。
- HUD 锚定屏幕边缘和底部中心；主要内容使用 VBox/HBox/Grid/ScrollContainer。安全边距为逻辑像素 14–22；窄布局隐藏工作台侧栏，改用页选择器，卡片单列；宽布局按可用宽度双列。实际窗口缩放会重排所有既有卡片组，不要求重新打开页面。
- 200% 字体/UI 缩放下保留舰况数字和防御弧，缩短辅助文字，站内右侧详情折叠以保证中央可见；服务列表和业务内容允许滚动，不把关键出港、返回和取消操作放在视口外。
- Alt释放光标后点击雷达回波只选择目标，范围按钮切换只读导航定义中的500米/2公里/6公里档；普通回波受局部探测上限约束。天体符号只投影航向，不执行交互、不参与碰撞，也不宣称天文距离。目标连线和离屏箭头不自动转舰；具体交互与显示边界见 [31](31-EVE第二银河参考与易用性改版.md)。

本轮保持主程序调用的 tick/read adapter：界面每 0.25 秒刷新一次状态，舰况签名未变则不重复更新仪表，目标按钮复用而不循环重建。没有把这一兼容实现声称为完全事件驱动架构；业务命令仍只发 requested 信号，UI 不写游戏状态。

### 生命周期补充验收

实际发布包试玩发现首次悬停读取尚不存在的 `hover_tween` 元数据，以及已销毁音效/特效引用进入带类型的 `Array.filter` 回调后报错。UI 先检查元数据存在，再读取和取消旧动画；排队的悬停回调、目标排序与标记绘制均在转换类型前检查对象有效性。表现层改为逆序移除无效引用，在暂停、命中、逐帧维护与退出入口先清理再遍历。首页“继续最近航行”缩短为“继续航行”，避免已有存档时按钮文字换成两行。

补充测试还发现暂停页 UI 短音效继承父节点禁用状态，不能自然触发 `finished`；UI 音效节点改为 `PROCESS_MODE_ALWAYS`，可在暂停菜单自然结束并释放，世界音效仍受暂停规则控制。

[生命周期测试](../jiaoben/tests/ui_lifecycle_v2.gd) 的最终 [headless 日志](../jiaoben/logs/ui-lifecycle-v2-headless.log) 与 [原生 Metal/CoreAudio 日志](../jiaoben/logs/ui-lifecycle-v2-native.log) 均为 **27/27 PASS，engine_diagnostics=0**，完整日志未见 ERROR、WARNING 或资源泄漏。覆盖首次/重复悬停、快速切换业务页、控件销毁、从独立旧档继续、各表现清理入口、暂停音效自然结束、失效目标/特效引用及退出清理。测试捕获引擎、脚本和 shader 诊断，使用独立临时进度库，不接触玩家档案。

### 实际发布包诊断与交付边界

客户端新增固定 `--xj-verify-presentation` 诊断入口，由 [发布包诊断](../code/runtime/presentation_diagnostic.gd) 执行内置检查，不加载外部测试脚本。主程序只接受独立且不存在的 `jiaoben/tmp/` 数据库路径，构建脚本为每次运行创建新目录和 fresh 数据库，拒绝复用已有档案。该入口用于实际打包客户端的 Metal/CoreAudio 检查，不会读写正式玩家进度。
