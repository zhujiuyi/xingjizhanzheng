# 界面可用性与视觉验收

状态：单人客户端界面已经实现并完成本机原生验收。本文记录界面证据，不替代任务、战斗、数据库兼容和发布包的专项验收。2026-10-03。

## 1. 实现边界与玩家行为

实现入口：[ui.gd](../code/runtime/ui.gd)。保留 `requested(action, target, quantity, extra)` 信号和 `bind`、`show_page`、`notify`、`input_blocked`、`set_operation_status` 方法；界面读取当前 typed DTO 和冻结 catalog，只提交操作意图，不直接修改玩法状态。

| 区域 | 已实现的可用性规则 |
|---|---|
| 飞行 HUD | 舰船与星系中文名，护盾/装甲/结构、电容、热量、速度和载荷；当前顺序目标；扫描完成比例和周期剩余时间、采矿周期状态及停止按钮。紧凑布局改用百分比、合并载荷，信用点完整值保留在服务页与暂停页。界面重绘节流不改变模拟频率。 |
| 目标 | 距离排序，按钮按实体 ID 复用，刷新不反复重建并抢焦点；教学航标显示“前进航路标”“转向航路标”；敌舰三条状态条读取实际定义最大值和实例当前值。鼠标位于目标/作业/等待面板时阻止飞行输入。 |
| 站点服务 | 页面选择器与固定页头关闭按钮；服务页只在停靠时开放。维修展示同一业务接口给出的信用点及结构部件需求。 |
| 舰队与借船 | 中文舰名、资产用途和位置；专业借船通过 `loadout_id` 解析真实舰型，展示任务/资格/补领等待原因。归还入口仅在指定返回站点可用。 |
| 仓库与配装 | 只展示当前站点及驾驶舰的有效货舱/矿舱，排除异地和配装槽物品；政策用中文表达。槽类型与序号友好显示；启用和关闭分别发送 `on` / `off`，实例操作数量固定为 1。 |
| 市场与工业 | 物资、船体和出售筛选；当前数量报价复用 `economy.quote` / `quote_ship`，维修和制造复用对应业务接口；显示含税/声望后的总价，不把基准价描述为成交价。数量上限读取数据库，船体单次购买固定为 1。保护资产与回购额度不足时禁止出售按钮。船体制造只展示本站有规格的船坞。 |
| 任务 | 当前站点/星系、可接取、进行中、全部四种筛选，每页最多六张卡；进行中/可交付优先，可接取其次，未解锁与已完成后置，同组稳定排序。新世界第一张为“出航准备”。按数据库的全部 11 种目标翻译，显示前置、解锁、重接冷却、窗口限额及指定交付站。教学内部短码不展示为玩家标题。 |
| 存读档与退出 | 等待、写入、加载、跃迁状态由 Main 更新；等待保存栏独立于滚动正文，可取消。暂停页提供继续、船毁救援、保存、读档、设置、保存退出及明确“放弃未保存进度并退出”；后者提示下次恢复最后成功档。成功文案由真实提交结果触发。 |
| 设置 | 使用 `store.preferences()` 的实际值，赋值后才连接滑块事件；打开页面不发写入。鼠标项明确为“观察镜头鼠标灵敏度”，适配 0.002 附近的实际范围；已有值不会静默重置。主音量、特效强度和画质保持原偏好。 |

字体使用 `SystemFont` 回退顺序 PingFang SC → Microsoft YaHei → Noto Sans CJK SC，并允许系统回退，不复制系统字体文件。本机中文关键字形检查及实际截图正常；Windows 字体与原生界面的结果仍需 Windows 实机确认。

## 2. 可重复验收

脚本：[ui_usability.gd](../jiaoben/tests/ui_usability.gd)；最终原生日志：[ui-usability-native.log](../jiaoben/logs/ui-usability-native.log)。Godot 4.7.2，macOS / Apple M1 Pro，Metal 4.0 / Forward+。

- 原生 **201 项检查全部通过**，最终日志无 `ERROR` / `WARNING`：设置读值且不写回、实际数量/含税报价、船体数量、关闭设备意图、本地库存边界、任务排序与分页、全部目标类型、中文字体、目标控件复用、保存取消/放弃退出意图、NPC 最大值、扫描状态、实际鼠标悬停阻止飞行输入。
- 对 1280×720、1440×900，分别按 100% 与 200% 内容缩放检查 11 个页面的固定页头、关闭按钮、滚动空间和等待取消入口；高缩放长列表通过垂直滚动访问。200% 活跃作业停止按钮仍在屏幕内，且不与通知文字重叠。
- 原生鼠标悬停检查需要真实显示服务；headless 运行跳过这一项并明确输出说明，不能用 headless 结果宣称原生指针验收。
- 新增视觉脚本只使用独立 `jiaoben/tmp/` 验收数据库。NPC 三层损伤与扫描中的组合截图使用临时 typed DTO/作业夹具，未保存；它证明状态呈现，不证明战斗或扫描业务完成。
