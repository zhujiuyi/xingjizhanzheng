# 星际战舰 · 玩法设定

版本：v0.1-draft。日期：2026-10-02。状态：第一版玩法设计稿，尚未实现或平衡。

已确认需求见 [总纲](06-游戏设定总纲.md)。舰船能力见 [战舰设定](08-战舰设定.md)，世界规则见 [世界观](07-世界观设定.md)。本文件中的机制、任务范围与难度是提案。

v0.2 评审补充：用户已确认首版单人闭环并保留联机接口。可执行初始流程、输入、停靠、失败、存档和跨区恢复统一以 [实现契约](17-首版行为与实现契约.md) 为准；数值以 [数值基线](15-数值系统与平衡基线.md) 为准。

## 1. 任务与基本循环

基础循环为 **准备 → 出航 → 执行 → 撤离/返航 → 交付 → 改装**。任务提供明确目标，同时允许玩家在途中发现其他机会。

| 任务类型 | 主要操作 | 适合舰船 | 成功结果 |
| --- | --- | --- | --- |
| 航路侦察 | 扫描异常、核验虫洞、带回出口情报 | 雨燕级穿梭器、提灯级探索护卫舰 | 星图更新，获得情报奖励 |
| 资源采集 | 找矿、维持采集距离、管理货舱、返航 | 铁砧级采矿舰 | 原矿进入仓库，完成交付或加工 |
| 威胁清除 | 识别目标、接敌、武器与防御管理 | 游隼级战斗护卫舰 | 区域更安全，获得报酬与回收物 |
| 护航/救援 | 跟随目标、拦截敌人、牵引或运送物资 | 战斗舰；后续运输和支援舰 | 友方到达锚点或完成救援 |
| 遗迹调查 | 扫描、接近、分析设施和收集记录 | 探索舰 | 获得资料、元件或后续任务 |

首个任务链是：操控训练 → 内置基础扫描与门校准 → 借用铁砧进入回声带试采并返航交付 → 教学游隼配装与战斗 → 提灯自主探索。初始能力与借船来源足够完成每一步；具体奖励和可驾驶/制造解锁分别记录，见实现契约 T0–T4。玩家可在允许的稳定边界保存，再读取继续。

## 2. 舰船操作与镜头

默认采用第三人称直接飞行，提供推力、转向、减速/辅助稳定和任务交互。舰船的运动与镜头控制分离；鼠标环绕不应意外改变航向。是否采用鼠标指向航向或独立转向键，在样例中比较后再固定键位。

穿梭器和护卫舰重视灵活性，采矿舰和较大舰船具有更明显惯性。辅助稳定帮助控制速度，完整六自由度作为可验证方向，不先要求复杂真实航天模拟。

| 镜头模式 | 目的 | 转换规则 |
| --- | --- | --- |
| 跟随 | 常规飞行、操控与周边观察 | 默认模式，随舰船尺度调整距离 |
| 自由环绕 | 观察外形、环境、采矿方向 | 保持飞行状态，退出后平滑回到原模式 |
| 目标战斗 | 判断双方距离、攻击方向和撤离路径 | 锁定目标后启用，可解除锁定 |
| 船头观察 | 小艇穿梭、近距离导航和沉浸 | 先使用前向相机；完整驾驶舱后续评估 |
| 战术观察 | 看清局部战场、航标和队友 | 拉远观察并显示必要标记；星图独立打开 |
| 穿越镜头 | 表现虫洞进入与退出 | 有限时间的镜头序列，结束恢复此前模式 |

震动、视野角变化和扭曲效果提供强度设置。重要交互用清晰标记表达，不依赖玩家从高亮粒子中辨认目标。

### 本轮确认的导航指令补充

保留现有六轴手动飞行，增加选中目标后的本星系跃迁、普通接近、三维环绕与停船。当前星系已知空间站可远处选择；跃迁先保存稳定起点、充能并按实际舰船转速对准，到站外后零速度停下，玩家再选择停靠。远处直接点停靠则自动物理接近，抵达后由原业务服务二次核验，再进入站内场景。

交战中可以接近、环绕和手动撤离；跃迁、停靠继续受稳定条件和业务资格限制。X、停船或手动操纵取消自动导航；右键观察只改变相机。动态敌舰保留局部探测范围，不能使用已知站点的远程定位资格。星系内跃迁与虫洞跨系分别处理。具体交互、数据库参数、完整快照边界及尚待补齐的整机证据见 [32](32-曦航对标与导航交互改进.md)，不再把本轮已确认的自动环绕写成未决定的提案。

## 3. 探索与扫描

未知地点先呈现为异常信号。玩家在合理范围使用扫描设备，逐步获得类别、位置和危险提示，再决定是否接近。

首版流程为 **发现信号 → 靠近或调整扫描 → 完成识别 → 在星图登记 → 进入地点**。建议用简洁扫描进度与方向提示，暂不实现复杂多探针摆放界面。

探索舰优势体现为扫描效率、识别距离和情报完整度；战斗舰也能进行基础识别，但不会替代专业探索能力。重复读档不能让已完成的遗迹无限产出奖励；地点和奖励领取状态进入数据库。

## 4. 采矿与加工

矿脉由类型、可采量和风险共同决定价值。玩家接近矿体，开启采集模块，按周期将产物放入当前舰船货舱；模块需要能源，货舱满或目标枯竭时停止。

- 采矿输出、模块周期、距离、消耗和货舱容量均来自数据库。
- 矿脉剩余量与玩家货物在同一模拟边界原子更新，并在同一完整快照中持久化；业务成功与 SQL 保存成功分开提示，避免混合两套状态。采集成果与实物交付分别记录，交付时扣除当前合格库存再发奖。
- 基地加工把原矿转为材料，随后用于修理、模块制作或任务交付。
- 采矿船自卫有限；危险矿区需要选择逃离或朋友护航，而非依靠单纯更大的采矿船解决所有问题。

首版加工可即时完成；排队制造、设施升级和自动化生产作为后续内容，配方结构先保留扩展能力。

## 5. 战斗系统

建议同时包含需要朝向和瞄准的武器，以及依赖锁定的辅助武器/模块。实际射击手感通过样例决定，避免一开始叠加大量武器机制。

| 系统 | 首版方向 |
| --- | --- |
| 目标识别 | 敌我标记、距离、护盾/装甲/结构和攻击提示 |
| 防御 | 护盾 → 装甲 → 结构三层，恢复方式各有差异 |
| 能量 | 推进、主动防御、扫描与部分武器共享电容，持续火力与逃生需要取舍 |
| 武器 | 先验证一种直射能量武器与一种弹道武器；导弹和复杂电子战后续扩展 |
| 伤害与抗性 | 草案采用动能、热能、脉冲三类；数值与相克由数据库维护，先确保提示可理解 |
| 命中与效果 | 命中判定独立于拖尾、爆炸和镜头表现；关闭高画质不会改变伤害 |
| 撤退 | 保留通过距离、掩体或快速航行摆脱敌人的空间；进入跨区通道须满足条件 |

大小舰船通过火力、机动、射击范围、锁定效率和通行能力形成分工。大舰不自动命中高速小艇，小舰也不能无代价承担大舰火力；首轮伤害、抗性、射程和负荷公式见15，实际射界与命中按17验证，高级火控另行扩充。

敌方首版只需巡逻、发现、接敌、追击和脱离几个清晰状态。复杂舰队编队、电子干扰、隐身和无人机指挥后续逐项加入。

## 6. 虫洞穿越

穿越需要先完成发现和通行检查。过程建议为：

1. 显示目的地、通行资格、稳定性与返回条件。
2. 玩家进入触发区域并确认航行，取消时仍留在原星区。
3. 蓄能与入口镜头启动；成功检查后进入穿越状态。
4. 加载目标星区，演出星光、隧道与适度屏幕扭曲。
5. 将舰船放在目标出口安全位置，恢复飞行和此前镜头模式。

跨区状态由权威模拟管理，数据库避免出现“船在两个星区”或“进入动画播放完却未到达”的记录。存档在边界提交一致状态；穿越中断后的确定恢复方案以 [数据库方案](10-数据库与存读档技术方案.md) 为准。首版不要求逐帧保存穿越动画。

固定锚定虫洞门形成星系间的主要交通网络。玩家从星图规划经由哪些入口和出口，结合安全区、容量、势力服务与货物价值选择路线；普通飞行与星系内快速航行不跨越星系。游离虫洞提供需要扫描的额外路线，收益来自新情报、捷径和未探索产地，风险来自出口与稳定条件。

## 7. 配装、仓库与成长

基地提供换舰、安装模块、修理、加工和交付。配装按功能明确分为武器、任务设备、防御、推进和辅助模块，具体槽位与能源/结构约束见战舰文档。

换舰、拆装、维修和本地仓库转移需先停靠；船与物品必须实际位于该站点。容量、所有权和位置检查通过后整笔应用，远端资产不会因打开菜单瞬移。基础操纵不消耗电容，电容不足只阻止相应主动设备，不阻止基本返航。

成长由 **舰船可用性、模块蓝图、任务解锁和探索记录**体现。首版不采用必须等待现实时间的长期技能训练。玩家获得材料和任务许可后即可尝试新的角色。

基础经济以 NPC 服务和固定配置价格起步；任务奖励、商店价格、加工消耗和修理成本全部入库。供需模拟与玩家市场不是首轮必要条件。

## 8. 失败与恢复

默认建议采用适合私下试玩的恢复规则：舰船损失会使当前出航失败，部分货物形成可回收残骸；基地保留基础穿梭器或替代支援，确保玩家能继续任务。修理、损失比例和回收规则由数据库配置。

首版具体恢复地点、原实例销毁、唯一残骸、保障模块不可套现和教学任务重接按实现契约执行；所有来源与结果进入同一进度分支，不能只给船体加保障标签而放任附属模块出售套利。

单人允许手动读档，回退整个存档快照；不会声称这种模式具有不可回退的经济。更严格的损失模式可后续加入。多人房间如果实现，只由房主对整个世界执行保存/读取，客机不能单独回退库存或奖励。

## 9. 存档、数值与持久性

| 内容 | 保存要求 |
| --- | --- |
| 玩家 | 当前角色/舰船、资金、解锁、任务进度、发现情报 |
| 舰船 | 实例、类型、位置、朝向、速度、结构状态、能源、配装与货物 |
| 世界 | 区域发现、资源剩余、持久实体、遗迹状态、世界时间与生成种子 |
| 虫洞 | 连接实例、稳定条件、通行消耗、已知信息与跨区状态 |
| 业务结果 | 任务领取、奖励发放、制造/交易结果，以事务保证不重复或丢失 |
| 数值配置 | 舰船、模块、武器、资源、配方、任务、敌人、掉落、经济与通行规则 |

实时运动在内存中更新，不逐帧写数据库。保存时在明确模拟边界取得一致快照，持久化由数据服务执行。读档按内容版本恢复完整世界状态，并重新构造模型、镜头与特效。

手动保存、自动保存、存档槽选择、失败反馈和恢复备份属于基础体验，不能等内容做完再补。具体规则见 [数据库与存读档技术方案](10-数据库与存读档技术方案.md)。

首轮在稳定飞行、停靠或业务操作完成后的边界保存；交战和跨区加载期间请求可延后，并清楚提示。若加入战斗中即时存档，需扩充投射物、锁定和 AI 状态，不能只保存舰船位置便宣称完整恢复。

## 10. 首个闭环验收建议

玩家能从锚港出发，换用不同舰船完成一次扫描、采矿和战斗任务，穿过虫洞后返回，使用带回资源完成改装。

保存后完全退出客户端，再读档应恢复任务、舰船、货舱、位置和资源消耗；配置数据库调参后在支持的版本策略下生效。最后在 Mac 与 Windows 实际检查操作、画面和数据库扩展加载。上述均为后续验收要求，本轮仅完成设计文档。

## 11. NPC、敌对生态与安全区

安全区与 NPC 等级关联，同时保留任务难度差异。权威基础区间草案由 [星系设定](12-星系与势力科技设定.md) 管理：高安全区 1–5、中安全区 3–8、低安全区 6–12。区间重叠表示边界是风险梯度，而非跳进新星系所有 NPC 同时升级。等级数值未平衡，实施时从数据库读取。

| NPC 角色 | 行为与功能 | 难度扩展 |
| --- | --- | --- |
| 站点服务者 | 接发合同、交易、修造、研究和救援 | 由势力、服务许可和声望影响供给 |
| 航路巡逻者 | 在高安全区保护门与站点，响应明确求援 | 中安全区覆盖较少，低安全区不保证援助 |
| 资源作业队 | 采矿和运输，产生护航、补给或协作机会 | 进入争夺区域时需要玩家协助 |
| 掠袭小队 | 侦察、接敌、争夺货物，可能放弃不利追击 | 更高风险区出现配装协同与增援 |
| 遗构守卫 | 守护设施，分为哨戒、攻击、重装或支援单位 | 高阶设施采用多角色协同和有提示的特殊攻击 |
| 稀有目标 | 提供特殊材料、资料或任务线索 | 出现条件、冷却与奖励入库，避免无提示突袭教程 |

等级主要决定可用装备等级、能力预算和行为集合，再结合实际舰种与配装计算战力。重装与轻型敌人即使同级也有不同应对方式；高安全区危险任务在进入前显示推荐配置与退出路线。

敌方生成采用星系和地点配置，必要实例以稳定 ID 保存。加载存档不应将被击毁的关键敌人重生，或让已领取的稀有奖励重复发放。普通巡逻刷新由世界时间和规则控制，非客户端本地系统时钟。

## 12. 职业任务、势力与研究成长

| 任务来源 | 方向 | 解锁作用 |
| --- | --- | --- |
| 锚港主线 | 修门、恢复航标、追查断航事件 | 开通地点、设施与基础舰船 |
| 航路议会 | 侦察、导航、救援、运输保障 | 导航/传感资料与可靠航行设备 |
| 深铸联合体 | 采矿、加工、制造和护航 | 工业、防护与舰船结构蓝图 |
| 游弋同盟 | 快速运输、截击、情报交易 | 机动、武器和边境航路能力 |
| 遗构调查 | 扫描、回收、设施解谜和高风险战斗 | 特殊元件与实验性研究方向 |

声望针对势力分别记录。初版不把一次选择转化为永久阵营锁定；冲突合同在接受前说明影响。任务形式包括单次、任务链、可重复合同和区域事件，允许不同职业推进进度。

研究使用蓝图、资料、材料和可获得的设施条件，不依赖付费或长时间离线技能训练。星系差异决定资料和材料来源；装备代际与科技谱系影响配装方式，不只叠加攻击倍率。完整研发和制造规则见 [装备研发与工业经济](13-装备研发与工业经济设定.md)。

## 13. 贸易、物流与基地服务

运输将特色产地、制造站点和消费站点连接起来。货舱容量、航线长度、门规格、风险和维修消耗共同影响收益；运输舰与护航舰由此有明确用途。

站点不是全部服务的同一菜单：高安全区提供基础修理和采购，中安全区有专项工厂或研究设施，低安全区提供稀缺回收与交易机会。具体服务配置在星系数据库中关联，基础恢复服务始终有可达地点。

物品可以买卖、制造、回收或交付合同，避免独有产物迫使单人同时精通全部职业。核心市场先采用 NPC 库存、价格范围和供给规则；玩家挂单或复杂供需模拟属于扩展，但经济体系与对应数据结构先明确。

## 14. 朋友协作与 PvP

如确认同场联机，建议采用单人可完成、合作更有分工的任务：穿梭器侦察、探索舰扫描、采矿舰采集、战斗舰护航、支援舰维修或牵引。任务不能只因缺少某一种朋友职业而无法推进。

房间规则明确友军伤害、资源与报酬分配、掉落归属、加入/离开方式和存档权威。客机断线后保留已提交的资产变化，重连从房主获取状态；禁止把客户本地资产直接覆盖房主世界。

PvP 建议作为双方同意的演练或独立房间规则，不默认让朋友在生产和教学过程中互相损失。永久损失与 PvP 强度仍未确认，不能直接照搬 EVE 的公开宇宙对抗强度。

## 15. 世界事件、信息与游戏时间

完整设定保留航门修复/封锁、航路袭击、资源勘探、势力采购、异常信号和遗构激活等事件。事件影响具体地点、任务或产出，并提供可观察提示，不无声改变整个世界。

界面包括星图航线、扫描与危险提示、舰船与配装、货舱/基地仓库、任务日志、研发制造、市场、声望及存档菜单。常规飞行 HUD 只显示当前任务需要的信息，详细规则在对应界面展开。

声音用于推进强度、锁定、受击、护盾破裂、虫洞蓄能和危险警告；优先提供视觉与声音双提示。临时视听状态与持久业务数据分离。

世界时间、资源刷新、事件冷却、生产队列和 NPC 刷新由同一权威时间推进并持久化。首版离线不消耗虫洞寿命，不自动惩罚未登录玩家；联机与离线规则保持一致来源。
