# 战斗自动化与索敌环绕

v0.11.0；2026-10-04。武器/设备状态区增加三个独立勾选项，命令与真实武器、敌舰和导航连接。默认关闭；是当前飞行会话的临时命令，不改存档格式或另存数值。完整源与实际包身份见[26](26-开发阶段与交付记录.md)。

## 操作与行为

| 选项 | 已实现行为 |
| --- | --- |
| 自动战斗 | 对锁定敌舰逐个使用启用、完整且就绪的武器；每门武器独立判断冷却、射程、射界、视线、弹药、电容及热量，继续真实支付和投射物/命中流程 |
| 自动环绕 | 对锁定敌舰环绕，舰首持续朝向敌舰以满足固定武器射界；不因环绕默认开启射击 |
| 自动索敌 | 开启时选择本星系最近的存活可探测敌舰，等距按稳定ID；锁定后保持到目标被击毁、离开或失去探测，再找最近者；超过有效武器范围自动接近，进入范围后按另两项继续 |

索敌使用现有传感距离和敌群揭示资格，不把远处未揭示成员、敌群信标、站点、矿体、残骸当作可攻击敌舰。当前内容中的`npc`对象均是敌舰，没有新增阵营数值或许可系统。无可用武器仍可索敌，显示无武器并不追击；无敌舰显示等待，不发虚假攻击。距离更近的另一敌舰经过时不会反复抢走当前有效锁。

战斗锁与浏览对象分开，查看空间站或另一敌舰不改变已接受战斗目标。自动索敌实际取得新锁时更新所选对象；关闭索敌后保留当前锁，目标丢失后不会自行找下一敌。明确选择新敌可在无锁时恢复已勾选战斗/环绕。目标卡“对此开火”仍是明确换火命令，“交战”开启真实接近和开火并保留已勾选环绕/索敌。

三个勾选项即时回显权威控制器状态，设备行和目标卡读相同锁及状态。普通布局同行显示状态，紧凑布局由tooltip保留说明；支持真实鼠标、Tab/方向焦点、Space/Enter勾选。选项焦点中的Space和上下箭头不再同时向船体提交上升/俯仰，W/A/D/C和滚转继续按操舰规则处理。

## 武器、导航与接管

有效中心射程取启用、完整武器各自数据库射程减真实挂点偏移的最小值，覆盖混装武器。冷却、暂时电容不足或弹药不足不改变导航半径；武器启停/损坏会重算。每次实际开火仍按真实挂点距离与射界、视线复验，范围规划不直接扣血或扩大武器能力。

接近与环绕复用现有SQLite导航规则，现有NPC接近400米、环绕500米；按有效中心射程缩短，并用现有到达容差留范围缓冲，避免短射程大舰在范围边缘反复切换。真实两舰碰撞体包围半径加数据库安全裕量作为下界，无法保持安全间距的命令拒绝并显示原因。接近在范围内完成减速，索敌单开时保持观察目标和制动；环绕开启则接替为面向敌人的侧向运动。

新战斗导航只有目标、模式、范围与几何全部通过后才接替旧的非跃迁订单；无效请求保留旧导航。普通接近/环绕保持旧规则，普通环绕舰首仍朝切线。每个物理步只执行一次真实Flight模拟；控制器只决定订单或写意图，不额外推进世界时钟或舰船。

| 边界 | 行为 |
| --- | --- |
| W/S、A/D、上下移动、俯仰/滚转手动输入，X停船 | 取消自动环绕和自动索敌，避免下一步抢回运动；自动战斗与当前锁保留。X按原规则停船，手动接管保留惯性 |
| Z | 已勾选自动战斗时优先关闭，即使当前有效射击目标为空；无战斗订单时启动所选合法敌舰。浏览另一对象不让Z误开启新的目标 |
| 明确普通导航 | 成功接受后移交运动控制并取消环绕/索敌；不因无效替换丢掉当前订单 |
| 跃迁、虫洞、停靠、换舰、救援、读档/新世界 | 按既有过渡边界清会话命令；旧存档实际状态和继续端点保持 |
| 暂停/菜单、TextEdit、失焦 | 暂停冻结真实模拟；已有接受订单与手动输入隔离继续遵守原规则，不靠焦点变化突然改敌或发新手动指令 |
| 普通保存等待 | 三个选项仍可操作，允许结束持续战斗/运动；取消等待保留当前设置，不改变已支付设备周期和弹药 |
| 退出/返回标题保存等待、真实写入/读取、跃迁/传送 | 禁止新选项命令；退出先清全部自动订单，取消退出保存不自动重新开启 |
