# 文明贡献与指挥资格

2026-10-11。按[单机矩阵](51-单机完善实施与验收矩阵.md)S16实施；本文件区分实施规则与尚待实测的平衡。S17/S18战争准备、重建和边疆危机继续保留，不以本阶段资格界面代替战争流程。

## 现有行为与本阶段目标

当前三个文明各有八级声望爵位；舰队战争要求第五级、2600声望，声望可以通过矿物捐献取得。已有战争包含目标集结、清敌与驻留占领。探索已保存救援/遗迹成果，行动已保存拆除成果，承运已有实际送达与结算账本。这些真实结果可作为能力证明，不需要再复制一套战斗或货物系统。

新增文明考核，要求玩家在登记后完成侦察、补给、救援和作战四类行动，再于所属核心站取得指挥资格。爵位、专属舰和科技原权限保留；新资格参与新战争委托的受领判断。正在进行的旧战役继续履行，不追溯清除战役、主权或奖励。

## 当前实施值

登记需要当前效忠文明的第二级爵位（400声望）及远域航路许可，在核心站进行。四项要求是完整遗迹调查1次、实际承运送达累计6批、完整救援1次、完整拆除2个装置；两处遗迹、两处救援、两条承运均可作为对应来源。认证一次发放4000信用点和400声望。新战争仍要求原第五级爵位（2600声望）；这些数值属于本阶段实施值，尚未作为自然成长平衡结论。

## 实施规则

- 在当前效忠文明核心站登记，登记门槛与奖励从新增SQL定义读取。各文明考核、证据和已授资格分别保存，改换效忠不清空旧成果。
- 侦察读取登记后实际结算的完整遗迹调查，救援读取完整护送成果；补给读取已结算承运的实际送达批数；作战读取完整拆除行动的真实成果。每条证据绑定来源、代次与现有结算记录。
- 登记以前已经结算的成果不追溯折算；以实际结算时间为准，捐献不产生能力证明；失败、部分成功、退回货物和重复领取不能伪造完整能力考核。明确注明允许部分批数累计的补给条目。
- 一项实际成果只归属取得时的效忠文明；重复动作、加载、过期界面或改换效忠不能再次记账。达到相应要求后停止增加冗余记录。
- 考核期间允许正常暂停、退出和换舰；承运、消耗及教学资产继续遵守各活动原有的所有权与物资保护规则。不发放免费永久舰队，不要求专属舰才能获得初次资格。
- 全部任务完成后在当前效忠文明核心站认证，一次性发放定义内有限奖励。新战争仍同时核对原爵位、核心站、目标主权、任务借船清理和既有战争条件。

界面沿用文明页，显示四行“项目 / 当前值 / 所需值 / 状态”和登记/认证操作。缺口只显示短原因；定位及前往复用对应探索、行动或承运导航，详细说明按需展开，避免增加整屏文本。
