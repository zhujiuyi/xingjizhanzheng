# 资源表现与界面实施规格

状态：首版 B 的实施草案，目标 Godot 4.7.2；定义可编码的占位资源和界面契约，美术、音效与运行中的游戏此后已实现；界面规则以 [76](76-界面设计规范与全界面整改.md) 为准，本文只作历史契约。规则以 [17](17-首版行为与实现契约.md) 为准，数值以 catalog 为准，模块边界见 [21](21-模块接口与开发验收规格.md)。B 仅锚港、回声带与四艘舰船；其它星系和高级舰种沿用同一资源接口，按 C/D 扩展。

## 1. 资源权威与导入约定

- 单位米、比例 1，Godot 世界和船体 `+Y` 向上、`+X` 向右、`-Z` 为舰首。Blender 建模以 `+Y` 为舰首、`+Z` 向上、`+X` 向右；本轮 glTF 导出导入实测映射 `(x,y,z)→(x,z,-y)`，Nose/Up/Right 三标记通过，证据 [godot-glb-axis.log](../jiaoben/logs/godot-glb-axis.log)。导出后仍检查轴向，不用负缩放纠正；根节点旋转、缩放归一，造型变换烘焙到视觉子节点。姿态运行时用正交 Basis/Quaternion，保存四元数分量，不按欧拉角拼接连续转向。[Godot 3D 变换](https://docs.godotengine.org/en/stable/tutorials/3d/using_transforms.html)
- **模型尺寸、碰撞形状、挂点局部变换是版本化资产结构**，权威在 `.tscn`/模型；本文件的尺寸表是该资产版的验收描述，不再复制到数值数据库。镜头、LOD 距离、粒子预算、音量等可调参数仅存 catalog；UI 布局、颜色、键位映射属于表现资产。
- 碰撞几何影响命中，同一内容档必须绑定 `asset_version` 和 manifest 哈希。旧档恢复前验证资源版；缺资源或版本不兼容须拒绝加载并说明，不能静默换碰撞体。修改外形、碰撞或挂点需要新资产版和兼容决策。
- 资产 ID 是稳定键，路径由 manifest 解析；运行时不能用中文显示名推导路径。正式资源无需互联网。新增美术不能覆盖 Blender 原文件和可复用 glTF；导入缓存不作为原始资源。

manifest 的逻辑 SHA-256 对去掉 `manifest_sha256` 自身字段后的 UTF-8 JSON 计算：键排序、无空白、非ASCII不转义；此哈希用于 content_snapshot.asset_manifest_sha256，不是完整排版 JSON 文件的字节哈希。资源 entries.sha256 分别校验对应文件原始字节。当前逻辑哈希为 `d0b0e29be0db58cb96f066be2dbbc284d9ae8915189322b1d2168e758b103890`。

场景共同节点约定如下；节点路径是工厂绑定接口，实例 ID 由工厂注入，场景文件不预置实例 ID。

```text
ShipBody (CharacterBody3D; metadata ship_def_id / asset_id)
├─ CollisionShape3D
├─ VisualRoot
│  ├─ Hull / Silhouette / NoseMarker (MeshInstance3D)
├─ Hardpoints
│  ├─ weapon_0 [等：存在槽位均有 Marker3D]
│  │  └─ muzzle (Marker3D; local -Z 发射轴)
│  ├─ work_0 [有 work 槽才存在]
│  ├─ utility_0 [等]
│  └─ structure_0 [等]
├─ FXAnchors / engine_left / engine_right (Marker3D; +Z 排气)
├─ CameraTarget / FrontCamera (Marker3D)
└─ InteractionAnchor (Marker3D; 船体原点)
```

每种槽从 0 独立编号。挂点稳定键 `(ship_def_id,slot_type,slot_index)`；节点 metadata 同时写 `slot_type`、`slot_index`。`weapon_0` 不是“第一个所有类型槽”，装配顺序不影响挂点。所有 catalog 合法槽必须有一个挂点，不能只给初始已装模块建挂点；一个挂点也不能有多个槽别名。挂点是模型呈现和发射起点，攻击范围、角速度、伤害、设备能力均由 catalog 和权威模拟决定。

## 3. 物理碰撞与查询

B 舰船使用 CharacterBody3D `MOTION_MODE_FLOATING`，脚本按模拟速度调用 `move_and_slide()`；无重力、落地或跳跃规则。它适合脚本驱动并支持滑动碰撞；这是实现选择，不表示 Godot 自动提供航行逻辑。[CharacterBody3D](https://docs.godotengine.org/en/stable/classes/class_characterbody3d.html)

| 物理层序号 / bit 值 | 名称 | 对象与 mask |
| --- | --- | --- |
| 1 / 1 | world_solid | 矿体、站体、固定障碍；layer=1 或 1+64，mask=2 |
| 2 / 2 | ship_body | 玩家/NPC 同层；layer=2，mask=1+2=3；过滤自身，不用物理层表示敌我 |
| 3 / 4 | projectile_proxy | 可选调试/表现 Area3D；layer=4，mask=0，不能触发第二份伤害 |
| 4 / 8 | interaction_proxy | 可交互区域；layer=8，mask=2；提示候选仍需模拟复核距离/目标条件 |
| 5 / 16 | gate_trigger | 门入口 Area3D；layer=16，mask=2；只提示，穿门须 TravelService 命令 |
| 6 / 32 | dock_trigger | 站点停靠 Area3D；layer=32，mask=2；只提示，停靠须业务复核 |
| 7 / 64 | camera_occluder | 站体/大障碍同时占此层；跟随相机 SpringArm mask=64；忽略本舰与普通粒子 |

其余层保留，不由单场景私自使用。玩家与 NPC 相撞仅滑动/停止，B 不算撞击伤害。攻击在物理 tick 对前后位置作扫掠，命中查询 mask=3，排除发射舰 RID；最近有效实体/障碍阻断弹道。敌我、任务资格、已毁状态用实体数据过滤，不能把敌人全放一层绕过友方阻挡。激光与采矿束的视觉长度跟随权威命中/目标事件，不反过来提供命中。

交互 Area3D、相机碰撞和武器查询必须各自独立。触发区半径、停靠/门距离和速度条件来自 catalog；场景工厂按数值配置生成 Shape，不把范围写入场景。碰撞层/掩码是接口协议固定常量，不是平衡参数。[碰撞层与掩码](https://docs.godotengine.org/en/stable/tutorials/physics/physics_introduction.html)

验收：弹丸高速不穿过大矿体；自身不误命中；透明粒子不阻挡；相机进窄处收缩但不中断船体移动；触发区无法绕过范围、速度、交战和门状态检查。

## 5. 镜头与性能预算

CameraRig 与船体解耦，跟随 CameraTarget，前视绑定 FrontCamera，战术视角面向本舰所在的局部空间，不显示另一个星区的实时实体。V 按 follow→front→tactical 循环；按住右键只转观察相机，释放后回归船体方向，不能同时把观察移动变成姿态命令。所有模式采用唯一 Camera3D；切换时插值，不切换模拟时间或目标 ID。遮挡用 SpringArm3D，显式排除本舰，读取数据库的 margin；它沿自身 Z 方向移动直接子节点，因此镜头 rig 必须验证朝向。[SpringArm3D](https://docs.godotengine.org/en/stable/classes/class_springarm3d.html)

`camera_profile_defs` 每船、每 mode 一行。follow 默认 distance/height/look_ahead_m 为雨燕 55/14/12、提灯 75/18/18、游隼 80/20/18、铁砧 140/34/25；tactical distance/height 为 90/110、120/150、130/160、210/260，look_ahead=0；front 使用固定挂点，distance/height/look_ahead=0。这些表述用于核对 DB 草案，运行不能读取本段数字。FOV 为 follow 65°、front 75°、tactical 55°；near 0.2 m、far 12000 m；位置/旋转平滑 0.18/0.12 s，碰撞 margin 0.5 m。follow 缩放范围为默认距 0.6–2.5 倍，tactical 为 0.75–2 倍，front 不缩放。

数据库 profile_id 分别为 `camera_swift_<mode>`、`camera_lantern_<mode>`、`camera_kestrel_<mode>`、`camera_anvil_<mode>`。字段为 `fov_deg,distance_m,height_m,look_ahead_m,near_m,far_m,zoom_min_m,zoom_max_m,position_smooth_s,rotation_smooth_s,collision_margin_m`；mode/ship_id 为关联键。presentation_defs 使用固定 `presentation_id` 与互斥 `value_integer/value_real`、`unit`，禁止脚本表达式或任意可执行配置。

distance_m 表示沿船体局部 `+Z` 的后退距离，height_m沿局部 `+Y` 上移；跟随看向 CameraTarget 向局部 `-Z` 前移look_ahead_m的位置。战术模式的高度和后退按星区Y-up基准偏移，俯视本舰，不跟随其滚转；front完全取固定挂点的船体变换。缩放改变distance_m并按同倍率保持height_m，front不缩放。平滑时长用秒，采用delta无关的插值；相机不拖动权威船体。

输入：camera_mode、当前相机偏好、船型 profile、权威姿态。输出：镜头变换和屏幕投影；camera_mode 进存档，用户音量/灵敏度偏好另存 preferences。验收：四船舰首/目标可见；滚转后镜头正确；窄处无穿站体；暂停/存读档不重置模式。鼠标灵敏度及平滑偏好是用户设置，并不修改舰船 turn_rad_s。

| 参数组（presentation_defs） | 默认草案与降级规则 |
| --- | --- |
| 参考负载 | 1920×1080、60 FPS 目标；须在实际 Mac/Windows 硬件记录平均/低帧与实例数后再宣称达标 |
| LOD 距离 | near≤300 m，mid≤1000 m，far≤3000 m，超 far 无粒子；几何轮廓/重要标记按相机可见性保留 |
| 引擎 / 爆炸 / 弹道粒子 | near 64/192/16，mid 24/48/8；far 为无粒子的光晕或线段，不能遮目标 |
| 同时效果预算 | 实例 64、粒子 4096、动态灯 4、每船盾击 2；不为每弹丸建动态灯，不启用弹丸灯阴影 |
| HUD 标记 | 目标 24、屏外 8；排序为当前目标→任务→危险→距离，未入选仍可通过目标列表查找 |
| 音频默认值 | master -6 dB、music -18 dB、sfx -9 dB、ui -6 dB；并发声音 24，用户设置可覆盖 |

VFX 使用 `GPUParticles3D`、简易 emission 材质、网格盾击和线段；需要正确 visibility AABB，不能在镜头外滥发。粒子用于表现，不负责碰撞、伤害或资源结算。[GPUParticles3D](https://docs.godotengine.org/en/stable/classes/class_gpuparticles3d.html)

超预算时按距离/事件重要性减少粒子，先移除远处引擎和重复盾击，再缩减爆炸；舰船销毁、命中、货物结算事件不可丢失。关闭粒子、声音和镜头震动应仍能完成全部任务。镜头震动首版默认关闭，后续加入也必须有关闭选项并由 DB 给默认参数。

## 6. 特效与音效事件表

| EventKind / 资源 ID | 必需字段 | 表现与寿命边界 |
| --- | --- | --- |
| weapon_fired / `fx_kinetic_trail`, `sfx_weapon_kinetic` | event_id、tick、source、mount、起点/方向 | 一次轨迹；持续距离由权威弹丸/命中事件提供，不能自行命中 |
| weapon_hit / `fx_hit_kinetic`, `fx_hit_thermal`, `fx_hit_pulse` | 目标、接触点/法线、damage_type | 三伤害靠颜色与形状区分，同时 HUD 层级数值变化；每事件只播一次 |
| shield_hit / `fx_shield_ring`, `sfx_shield_hit` | 舰船、接触点、层 shield | 盾环；armor/hull 命中改火花，不继续假播盾 |
| engine_active / `fx_engine_glow`, `sfx_engine_loop` | 实例、推力/增推状态 | 循环与已付费增推周期同步；暂停静止，销毁停止 |
| mining_started/ended / `fx_mining_beam`, `sfx_mining_loop` | 模块实例、work 挂点、目标 | 周期束；中断立即停止，矿物增量仅结算事件更新 |
| scan_started/ended / `fx_scan_sweep`, `sfx_scan_ping` | 扫描目标、已完成状态 | 周期扫光；读档不重播已完成发现奖励 |
| ship_destroyed / `fx_ship_explosion`, `sfx_ship_destroyed` | 船、位置、wreck_id 可空 | 一次爆炸；船实例随权威销毁，残骸从唯一容器工厂建立 |
| travel_state / `fx_gate_ring`, `sfx_gate_charge`, `sfx_gate_exit` | transfer_id、TravelPhase | 充能/等待/退出分明；写档失败播错误并恢复起点，不播到达 |
| ui_result / `sfx_ui_confirm`, `sfx_ui_error` | action_id、结果码 | 成功/拒绝声音不替代文字；保存确认音只能对应 COMMIT |

B 使用程序生成的短音/简单占位音即可；尚未提供音频文件。声音循环 owner 是实体/模块/transfer，不以节点生成顺序当 ID；实体撤销或 epoch 改变须停播。3D 声音定位取已呈現实体，UI 声音非空间化；听觉事件必须有可视文字/图标。背景音乐可缺省静音，不能影响玩法验收。

profile_preference.master_volume 是线性0–1主音量：新用户由数据库 audio_master_db 转为线性值初始化，之后用户偏好覆盖主bus默认值，不再与 -6 dB默认重复相乘。其它bus读取各自DB默认；vfx_intensity为用户效果强度覆盖，不改变伤害和命中。

## 7. UI 线框、状态与交互

| 站点总览 | 站名、当前舰、信用点、可用服务、教学借船/归还说明 | 出港/切船/领取借船发 action_id；完成确认后刷新，不乐观生成船或扣费 |
| 仓库 | 容器、本地物品/非堆叠装备、quantity、quality、durability、origin/policy、占用空间 | 选择整数数量转移；保护/绑定物有标记，普通物与绑定物不得合并；失败保持选择并重读版本 |
| 配装 | 按 slot_type/index 分组、候选模块、供能/CPU/质量/排斥检查、变化预览 | fit/unfit 以实例 ID 和期望版本提交；容量提升不把当前防御/电容加满 |
| 交易 | station_id、方向 buy/sell、item_id、报价、整数数量、总额、库存、保护原因 | 确认时重新验价/库存；请求期间禁重复提交；金额来自同内容 DB/当前市场状态 |
| 任务 | 任务状态、前置、当前/目标、交付站/实物、借船、已领取奖励 | accept/abandon/deliver/teaching_handoff 区分；返航交付不自动抹除当前借船；一次 action 结果明确 |
| 虫洞面板 | conn/endpoint、目标区、载荷/费用检查、prepare/origin_save/loading/destination_save/committed/failed | 充能前可取消；冻结期间外部动作停用，失败给重试/取消；仅目的地 COMMIT 后显示抵达 |
| 存读档/退出 | 槽、上次成功时间、generation、deferred 原因、writing、committed、error、旧档版本 | 保存请求不等于成功；等待可取消，写库中取消须等最终结果；读档隔离旧 epoch；强退明确最后成功档 |

Esc 打开单人暂停菜单并冻结世界时间。站点窗/交易窗只在已停靠状态打开；打开飞行任务/地图侧栏不改变世界暂停，必须在页上标明。键盘焦点在文本/数量框时不发送飞行/开火；Esc 关闭最上层弹窗后才退出页面；确认键不得绕过 disabled 原因。数量输入只接受正整数，UI 限制不能替代服务端式业务验证。

色彩：蓝/青为导航与扫描、琥珀为注意/工业、红为危险；盾/甲/结构同时用文字和图形，不只靠颜色。所有失败提供中文短因与稳定原因码；技术路径、SQL 错误原文放日志，玩家看到重试/恢复方案。保留 1280×720 最小布局：HUD 不覆盖中心瞄准区，站点面板可滚动，200% 字体下关键确认/取消可达。

中文字体采用 Godot `SystemFont`，`font_names=["PingFang SC","Microsoft YaHei","Noto Sans CJK SC"]`、`allow_system_fallback=true`，在 Mac/Windows 使用本机字体，不复制系统字体文件；系统字体由首个可用字体名匹配。[SystemFont](https://docs.godotengine.org/en/stable/classes/class_systemfont.html) 构建验收必须对“星际战舰、护盾、装甲、采矿、虫洞、保存失败”等中文检查实际字形，缺字时阻断该平台 UI 验收，并提示安装上述可用中文字体。需要随包分发时应另采用有可核验授权的字体并保留许可证，当前没有字体文件交付，也不把英文默认主题当作中文保障。

## 8. 交付与验证门槛

| 工作项 | 输入 | 输出 | 完成判据 |
| --- | --- | --- | --- |
| 四船占位导入 | 本节几何、catalog 槽 | 四 `.tscn` + manifest | headless 解析通过；模型方向与挂点一致；无附带平衡数值 |
| 星区资源搭建 | anchor_defs、资源/NPC/信号定义 | 锚港/回声场景、锚点索引 | 既定 ID 唯一、出口位置安全、四船能离港与穿门，不把高级星区标成实现 |

| VFX/音频桥接 | EventDto、预算 | 有界效果池、事件去重 | 超预算/静音/无粒子也能玩；读档 epoch 清理旧事件 |
