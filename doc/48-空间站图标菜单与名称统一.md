# 空间站图标菜单与名称统一

v0.16.0在任务入口后增加“文明与声望”，导航清单升级为`service_navigation_v3`，当前共12个页面入口与13个图标。以下v0.15.2–v0.15.3段落保留改版来由，旧清单仍按其发布源码校验。

2026-10-07，v0.15.2–v0.15.3。用户反馈机库入口前四项使用大幅人物头像，后续功能只有普通按钮；同一功能在机库和服务页的名称不同。随后反馈“空间站服务”实际返回机库、标题重复，工业页同时出现顶部亮框。

## 实现

机库、服务页侧栏、小窗口下拉选择器、页面标题共用 `runtime/ui/service_navigation.gd` 的展示目录，统一名称、顺序和图标。入口顺序为：空间站、舰队与借船、仓库与货舱、舰船配装、站点市场、工业与回收、打捞鉴定、任务与合同、科技与设施、星域航路、暂停与存读档。“空间站”返回机库画面，机库菜单上方使用“服务导航”，不再重复显示同名标题和图标。

每项使用独立原创透明 SVG 功能图标，常规行高32逻辑像素，小窗口28像素；左栏支持滚动和键盘焦点跟随。移除人物头像和人员查看导航，保留机库中的原有3D人员。观察舰船、维修补给和出港是独立操作，出港仍走权威业务入口。教学和任务提示同步使用“任务与合同”。

停靠权限仍由原业务检查决定；飞行菜单不显示机库入口，停靠类页面在飞行时说明限制且不产生交易操作。此改动只涉及展示，不修改数值库、世界规则、存档格式或资产归属。

工业页初始配方未解锁且没有可用操作时，旧焦点回退到侧栏第一项，造成顶部“空间站”亮框与当前工业页金色选中同时显示。v0.15.3在正文无可用控件时优先聚焦当前菜单项；服务按钮的键盘焦点改为透明底细边框，非当前页的悬停/按下使用中性色，金色填充仅表示当前页。Tab仍可移动焦点，Enter仍进入对应页面，键盘焦点不切换页面或写入存档。

## 验收入口

`py jiaoben/verify_combat_v18.py --only service-navigation --native` 串行检查真实Main、fresh UUID测试库、六种分辨率/缩放、真实点击/Tab/下拉菜单、图标与名称一致、观察舰船、出港与飞行权限。加入 `--executable <Windows EXE>` 后通过固定诊断入口在实际PCK中加载同一测试Node，不传源码工程路径。内置发布表现与旧界面测试同步移除头像假设，保留实际3D机库相机回归。

当前图标和展示目录由独立 `assets/service_navigation_v2/manifest.json` 提供字节摘要；生成与检查入口为 `py jiaoben/build_service_navigation.py`。既有v1发布清单保持原字节并退出当前加载列表，其注册表摘要对应旧发布源；12个图标原字节不变。实际结果、包路径和摘要见[开发阶段与交付记录](26-开发阶段与交付记录.md)。
