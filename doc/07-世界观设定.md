# 星际战舰 · 世界观设定

版本：v0.1-draft。日期：2026-10-02。状态：原创设计稿，名称、剧情和区域规则尚未确认。

已确认需求、技术路线与设计范围以 [总纲](06-游戏设定总纲.md) 为准。本文件的“断航星域”、历史、势力与地名均为本项目创作建议。

## 1. 世界背景

人类曾依靠锚定虫洞传送门网络连接多个恒星系。一次被称作 **断航事件** 的空间异常使大量锚点失效，部分航路断裂，星系之间仍由指定的虫洞传送门连接，另有不断变化的游离虫洞等待发现。

失联地区的资源、遗构和求援信号重新变得值得探索。商业船队、航路维护者和边境聚落各自修复局部网络，统一秩序退化为站点间的协议。玩家从边境锚港出发，既要解决供能、修理和物资问题，也要判断下一条航路是否可靠。首版不引入消耗式燃料库存。

“断航事件”的真相保持开放：可以涉及旧网络过载、实验事故或静默遗构的活动。首版只通过日志和任务提供线索，不要求制作大规模剧情过场。

## 2. 玩家身份与主线

玩家是获得临时航路许可的舰队经营者，拥有一艘基础穿梭器和锚港的维护席位。初始目标是恢复锚港与附近资源带之间的联系，随后逐步拥有探索、采矿和战斗舰船。

首版起始资产、内置基础扫描、教学借船与四舰取得顺序由 [实现契约](17-首版行为与实现契约.md) 和 [数值基线](15-数值系统与平衡基线.md) 明确；基础装备不要求先完成尚不可执行的研究。

建议主线分为四段：

1. **恢复出航**：完成舰船检查、操控训练和第一次任务交付。
2. **点亮航标**：扫描异常，找到回声带入口，带回航路数据。
3. **维持补给**：获取矿物、修复关键设施、组织护航并查明袭击来源。
4. **进入未知**：解锁更危险的遗构区，在资源收益和返回风险之间选择。

玩家不是一开始就指挥庞大帝国；成长由可见的舰船、模块、仓库和地图发现体现。

## 3. 原创势力与视觉语言

| 势力 | 立场与行动 | 舰船和空间设施视觉 |
| --- | --- | --- |
| 航路议会 | 维护航标与通行规则，重视可靠情报和救援 | 简洁、均衡的结构，银灰与冷蓝灯光，清晰导航标识 |
| 深铸联合体 | 控制矿业与修造资源，偏好效率和耐久 | 厚重框架、外露管线与货仓，铜灰装甲、工业警示灯 |
| 游弋同盟 | 在边境经营机动船队，成员既有向导也有机会主义者 | 高速轮廓、局部不对称改装，暗灰船体与琥珀灯光 |
| 静默遗构 | 无人系统与未知技术遗存，其目标逐步揭示 | 黑曜几何表面、青色光路、异常悬浮结构，无常规驾驶舱 |

势力影响任务、商店供给、外观和行为倾向；不以现实族群映射优劣。玩家可使用多来源舰船，首版不设置不可逆的阵营职业锁定。

## 4. 星域层级与首版区域

世界在玩家视角分为 **星域 → 星系 → 局部星区/地点**。一个星系可以包括空间站、资源带、遗迹和多个虫洞门。首个版本可将一个星系的主要可玩空间实现为一个星区场景，但数据层保留星系与地点的区分；现有 sector_* 标识用于初期可玩区域，所属星系在区域表中关联。星图展示关系与已知情报；引擎不以一个坐标空间模拟真实天文尺度。

| 区域 | 建议 ID | 风险与内容 | 内容阶段 |
| --- | --- | --- | --- |
| 锚港 | sector_anchor | 友好站点、训练区、基础任务、仓库和修造服务 | 首个闭环 |
| 回声带 | sector_echo | 小行星资源、异常信号、无人目标与首个虫洞出口 | 首个闭环 |
| 熔脊 | sector_forge | 高价值矿物、工业残骸、需要护航的运输任务 | 扩充 |
| 静默渊 | sector_silent | 遗构设施、复杂通道与更危险的无人敌人 | 扩充 |

首个闭环只制作锚港与回声带；其他区域先保留在设计和数据库定义中，不预设必须立即建模。

完整星系清单、所属势力、产出、NPC 难度和门连接关系由 [星系与势力科技设定](12-星系与势力科技设定.md) 统一维护。本表只介绍叙事和阶段，不作为另一份产出或安全区数值表。

## 5. 风险分区

按用户要求使用 **高安全区、中安全区、低安全区**。这是本项目的分区方案，与 EVE 官方高安全、低安全和零安全三类的命名不同。

- **高安全区**：航标、巡逻和救援覆盖充分，基础生产与训练服务完善；常规敌人较弱，但有提前标明难度的任务区域。
- **中安全区**：覆盖不完整，势力边界与争夺较多，适合护航、运输、工业与中阶探索；敌人等级和协同行为上升。
- **低安全区**：友方支援稀少，敌对聚落与遗构活跃，稀缺产物和高阶资料增加；返航和补给需要事先准备。

“未知”是地图发现程度，不是第四安全区。已扫描的低安全区仍然危险；未知地点可以处于任何安全区。NPC 的等级区间与风险配置由数据库管理，权威草案见 [星系设定](12-星系与势力科技设定.md)。

区域风险还决定敌人密度、舰种、行为协同、掉落、任务和支援条件，不单靠血量倍率制造难度。首版不实施对朋友自动惩罚的复杂犯罪体系；PvP 如加入，采用明确房间规则和参与选择。

## 6. 航行与虫洞规则

**常规推进**用于局部操控；**星系内快速航行**用于已知远地点；**特定锚定虫洞传送门**用于跨星系。星系之间不通过持续普通飞行直接抵达。游离虫洞作为可发现的额外跨系通道，保留扫描与风险玩法。

本轮已确认将星系内快速航行实现为“本星系跃迁”：当前星系已知固定站点、航门等可作为定位锚点，准备阶段完成充能与船体对准，再到达目标外安全落点并停船。它不改变星系、不等同于穿过虫洞，也不自动进入空间站；移动敌舰和远景天体不作为跃迁锚点。普通接近、三维环绕及自动接近后停靠沿用实际飞行与停靠检查。规则、独立 SQLite 版本和实现/验收边界见 [曦航对标与导航交互改进](32-曦航对标与导航交互改进.md)。

锚定虫洞门有固定两端、通行规格和运营状态，在星图上形成航线网络；跨系时必须实际到达入口、通过准入检查并完成传送。门被修复、暂时封锁或开放新航线可成为世界事件。教程门保持双向可返回，剧情封锁不会截断玩家唯一恢复路径。

虫洞是一条已有的空间连接，穿梭器负责发现、标记、测量和通过它，基础穿梭器不会凭空创造任意出口。小型穿梭器更容易通过窄通道；较大舰船需满足容量和稳定条件。实际通行上限由数据库定义，界面在进入前显示能否通过。

首个教程门允许四种基础舰船通行，保留可靠返回路径，先验证完整体验。锚定门容量与游离虫洞寿命分开配置；后续游离虫洞引入衰减、通行负荷与重新扫描：

| 规则 | 玩家看到的内容 | 数据库记录 |
| --- | --- | --- |
| 连接与发现 | 已知/未知出口、扫描进度和航路标记 | connection_defs、玩家发现状态 |
| 通行资格 | 当前舰船是否可进入、预计负荷 | 通行容量配置、舰船实例质量 |
| 稳定性 | 可靠返回、衰减警告或即将失效 | 虫洞实例剩余稳定度和世界时间 |
| 跨区过程 | 蓄能、进入、隧道、出口和视角恢复 | 起点、目标、出入口 ID 与穿越状态 |

首版不要求离线期间虫洞寿命继续流逝。世界时间随游玩推进，存档中记录；后续联机改为房主推进，避免客机系统时钟改变规则。

虫洞失效不应产生无法恢复的软锁。撤离信标、备用航路或救援任务至少保留一种可行恢复方式，具体成本入库配置。大型舰船不由玩家切换到穿梭器后凭空转移；运输或跨区调度须有对应服务与规则。

## 7. 资源与技术

不同星系具有主要产出、特色产出与工业专长，产出稀缺性驱动跨系贸易。势力的武器、防御、舰船结构、引擎与传感技术有方向差异；玩家通过蓝图、研究、合同和声望接触不同谱系，不能把一个势力设为所有装备的绝对最优。

建议资源体系先保持简洁：

| 资源 | 用途方向 | 典型来源 |
| --- | --- | --- |
| 铁硅矿 | 基础结构、修理和工业模块 | 常见小行星 |
| 导能晶体 | 电容、护盾和扫描模块 | 特殊矿脉与遗迹 |
| 高密合金 | 舰船装甲、较大船体 | 加工与回收 |
| 遗构元件 | 解锁特殊蓝图与研究任务 | 遗迹探索和无人系统残骸 |

所有名称、产率、用途和价格为原创提案。原矿、加工品、组件与蓝图分别建数据库条目；首版配方只保留少量明确关系，避免资源目录膨胀。

独有产物主要限制自然产地或首发技术来源，不限制玩家只能加入一个势力才能获得。交易、委托和探索为跨职业获取提供渠道。详细科技、资源分布与装备制造链见 [星系与势力科技](12-星系与势力科技设定.md)、[装备研发与工业经济](13-装备研发与工业经济设定.md)。

## 8. 世界持久性与表达

星图发现、已完成任务、开通航标、消耗资源、仓库变化、舰船损失和遗迹状态必须进入存档数据库。临时粒子、镜头抖动和声音不进入存档；加载后根据业务状态重新表现。

世界故事优先用任务简报、舰载日志、设施外观和可发现记录传达。每条日志有数据库定义 ID；玩家读取、获得和完成记录存于进度数据库，避免重载后丢失情报或重复领取奖励。

本设定采用 EVE 的探索、区域风险与连接发现作为设计参考；具体官方事实及差异见 [EVE 参考与原创边界](11-EVE参考与原创边界.md)。
