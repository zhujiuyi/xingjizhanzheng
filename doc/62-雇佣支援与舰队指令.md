# 雇佣支援与舰队指令

2026-10-12。S19已在v0.27.0实际Windows客户端验收；完整单机目标继续按[实施矩阵](51-单机完善实施与验收矩阵.md)推进。构建身份、摘要和验证边界见[交付记录](26-开发阶段与交付记录.md)。

## 玩家用途

开放航路后，在空间站“舰队与借船”页面付费雇佣一艘护航或后勤僚舰。护航舰跟随并攻击合法敌人；后勤舰以有限预付储备修复主舰。雇佣资产不能拆装、出售或转移为私人舰体。

| 项目 | 护航 | 后勤 |
| --- | --- | --- |
| 雇佣费 | 800信用点 | 1200信用点 |
| 押金 | 3000信用点 | 4000信用点 |
| 租期 | 900世界秒 | 900世界秒 |
| 主要用途 | 物理火力协同 | 有限维修及弱自卫火力 |

每次只允许一份活动合同。暂停、退出不消耗租期，站内停留会推进世界时间。正常归港按实际装甲与结构损失扣除押金，护盾损耗不收费；雇佣费不退。损毁或在外僚舰随主舰损毁紧急回收不退押金，已脱离并开始后台返航的僚舰继续原结算。合同结果只结算一次。

## 指令和同行

太空“僚舰”入口提供四个短指令：

- 推进：跟随主舰，自主攻击附近合法敌人。
- 集结：停止主动攻击并返回编队。
- 集火：攻击当前地点中存活、可感知的合法敌人。
- 撤退：实际离开交战区，完成脱离准备后返航。

编队距离700米，通信距离12公里；失联不能接受远程集火。跃迁和跨门须实际集结到1600米内，站内解约也要求实际归队。撤退需离开交战位置1800米，准备6秒后脱离，后台返航120世界秒。脱离前的飞行、攻击、受击和维修使用真实物理；后台路程只推进合同计时。

同行逐舰检查质量上限，虫洞剩余容量扣除队伍总质量，费用按实际舰船数量计算。AU跃迁、航门和取消/失败共用权威规则；失败保留出发状态，完成时主舰、NPC与合同地点同时更新，不重置生命值或强化NPC。

## 有限支援与反馈

后勤合同预付60次维修，每3秒最多恢复30护盾或20装甲，需要1800米实际范围及视线。没有合法缺损目标时不消耗储备；重新雇佣需要重新付款。

界面只显示角色、剩余时间、状态、支援余量、费用和押金。通信丢失、目标失效、损毁、过期、返航与退款都有状态反馈；关闭视觉特效不改变判断。
