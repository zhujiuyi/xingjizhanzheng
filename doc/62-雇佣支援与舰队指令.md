# 雇佣支援与舰队指令

2026-10-12，S19实施中。本文明确本阶段规则和验证要求；未验收部分不作为已交付功能。总体范围仍以[51](51-单机完善实施与验收矩阵.md)为准。

## 玩家用途

空间站的舰队页面提供一个付费僚舰名额，可选护航或后勤。护航舰跟随并攻击合法敌人；后勤舰使用有限预付储备，在实际距离和视线允许时修复主舰。雇佣不赠送私人舰体，不能拆装、出售或转移雇佣资产。

两种合同都有租期、雇佣费和押金。离线或暂停不推进租期；在站内停留仍消耗世界时间。正常归港按实际装甲/结构状态扣除维修损失，退还剩余押金，护盾损耗不收费。损毁或在外僚舰随主舰损毁紧急回收不退押金；已脱离进入后台返航的僚舰继续原返航结算。新雇佣重新付款，结果只结算一次。

## 指令与实际行动

沿用推进、集结、集火、撤退四种命令。推进随主舰行动并自主攻击附近敌人；集结停止主动攻击、返回编队；集火只接受当前地点中存活的合法敌人；撤退需真实离开交战位置并完成脱离准备，然后进入有时间成本的后台返航。直接在站内解约也需僚舰实际归队。

僚舰有通信距离，失联后不能凭空接受远程集火。跃迁/跨门前必须实际集结；跨地点和跨星系沿用主舰的战略转移边界，取消或失败保留出发状态。虫洞容量计入同行僚舰，通行费用明确计入队伍。NPC基础能力在移动后保持，不能换星系自动升级或恢复生命值。

归港后的后台路程只模拟合同计时，不声称逐舰跨越无人地点；脱离前的飞行、攻击、受击和修复均使用实际物理。主舰救援、僚舰损毁、租期结束、通信丢失、敌人失效和旧面板请求各有明确结果。
