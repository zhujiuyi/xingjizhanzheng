# 单行业务列表与行内数量

2026-10-05，v0.13.0。按用户对仓储、市场和工业页的反馈改为单行操作：货物归属、持有量、操作数量和对应按钮在同一行，不再从页首公共数量框推测哪一项会被操作。适用版本、干净提交和实际客户端身份以[26](26-开发阶段与交付记录.md)为准，源码与实际包证据分开记录。

## 仓库与货舱

左右归属沿用[43](43-双列表仓储与行内搬运.md)：左侧只显示当前舰的货舱与矿舱；右侧显示本世界当前玩家已有的空间站仓库，当前站全部物品排在异地物品之前。

每件货物的图片、名称、持有数量与单位、所在地、搬运数量、小按钮在同一条横排。左侧所在地标明“货舱”或“矿舱”，右侧本地标明“当前站”，本站真实名称在列表标题及完整悬停说明中；异地行显示真实站名。长名称可省略，悬停可读完整名称、位置、设备耐久与品质等详情。保障、任务绑定和借用物资有单行短标记，不靠按钮颜色区分来源。

本地堆叠物资各有独立数量框，输入上限仍取数据库业务上限与真实持有量；设备和密封包固定1。左侧“存入本站”卸到当前站仓库，右侧“装入货舱”装入当前舰普通货舱。按钮正常宽76、紧凑宽68逻辑像素，不随整行拉长。保护物资仍不能手动搬运；当前舱容、全舰载荷或访问资格不足时禁用按钮，悬停说明具体原因。

异地行整体置灰，数量及操作位置显示“只读”“需前往”，没有数量编辑器或搬运按钮。不是将远站资产复制到本站，也不提供远程取货。其它停泊舰的货物、安装槽位和残骸仍不混入左右列表。

两侧分别滚动。窄窗口与高缩放保持同一横排，通过侧内水平滚动查看后面的列；表头与行使用相同列宽一起移动。Tab聚焦数量时露出整个数量控件及箭头，聚焦按钮时露出按钮，不改变另一侧的位置。实际搬运刷新后保留同页未操作行的数量、两侧水平与垂直滚动及适用焦点，剩余持有量不足时钳制输入，移空的行消失。

## 市场与工业

市场和工业页取消页首公共操作数量，每个可按数量办理的货品或配方在自己行内填写数量，其他行不随之改变。图片、名称、单位、成交数量或批数、单价或单位服务费、总价、真实库存与资格、操作按钮同排；详情移入名称与行的悬停说明，按钮采用紧凑尺寸。窄窗口通过水平滑条或Shift加滚轮访问后面的列，表头同步滚动，Tab可露出数量控件和按钮。

| 业务 | 行内数量的含义 |
| --- | --- |
| 购买物资，包括成品设备 | 本行购入件数或单位数；可多件购买，受实际库存和资格限制 |
| 出售堆叠物资 | 本条真实堆叠记录的出售数量；不是所有同名物资的合计 |
| 购买裸舰 | 固定1艘，无可编辑数量框 |
| 出售独立设备 | 固定1件，绑定具体实例，无可编辑数量框 |
| 制造与提炼 | 本条配方的生产批数；材料、产出和总服务费随本行批数更新 |
| 船坞制造 | 本条舰体配方的生产批数，每批产出1艘裸舰，不含设备和弹药 |
| 设备拆解 | 固定1件，绑定具体实例，拆解成功后该设备消失 |

数量列是“本次操作量”，持有量或站点库存另在状态列显示，避免与实际持有量混淆。市场单价与总价仍通过真实报价计算，保留含税、声望优惠和整数舍入；出售还检查回购额度与站点预算。锁定科技、缺货、余额不足、保护资产或其它资格失败仍显示原因并禁用本行按钮，不会影响另一行的数量或报价。

制造与提炼的悬停说明显示本次材料和产出，不只显示单批用量；材料仍只取本站仓库的普通自有物资。没有制造服务的站点不显示可生产入口，未解锁或材料不足不因新布局获得资格。拆解仍只针对符合原规则的本站仓库普通设备；保障、借用、绑定来源及冻结回收材料规则保留。

输入文本即使尚未按Enter，本行报价与资格也按当前合法整数更新；点击先检查输入，再提交该行数量和重新检查资格。空白、小数、文字、非正数或超出数据库业务上限的文本不能发送交易，不会悄悄按1办理，也不会改用别的货品行。实际经济服务沿原请求与消费路径再次检查当时条件。

数量框失焦时，Godot可能将空白文本恢复为先前合法值；界面在其规范化结束后重新计算该行报价和按钮资格。该同步只更新展示，不发交易请求，旧页面的延迟更新仍通过上下文校验拒绝。

## 刷新与数据边界

市场、工业数量是界面临时状态，不写入存档或数值库。同一世界、状态、空间站和当前舰下的页面刷新、市场筛选切换保留各行数量；普通离页重进恢复默认数量。页面刷新保留适用纵向位置及列表横向位置。更换世界、运行状态、站点或舰船后，不沿用原上下文的输入。

行回调绑定状态对象、catalog/gameplay实例、world/session/epoch、当前站、当前舰、页面代次、对应行和目标资产签名。离页、刷新、读档、换站、换舰或换世界后，旧行不能再提交；同ID资产的容器、定义或保护策略改变也要重新取新行资格。仓储继续使用自己的面板实例与同等世界/站点/舰船上下文守卫。不能只凭物品裸ID判断它仍是当前可操作资产。

本轮改变展示、独立输入及回调校验，不另设平衡数值、虚拟库存或新存档格式。材料、价格、配方、来源限制、容积与载荷仍由当前世界冻结定义和真实typed状态决定。
