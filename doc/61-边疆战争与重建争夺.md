# 边疆战争、重建与可逆争夺

2026-10-12。S17–S18实施中，尚未交付。按50/51的S17、S18推进，连接S02、S20、S21和S26；正式实施时仍以SQL定义和实际验证为准，不把下文数值建议写成既有事实。

## 目标与保护范围

八个可争夺边疆支持“中立 → 准备 → 作战 → 重建 → 受控 → 争夺 → 受控/中立”的可逆循环。原十个中立出生航路和三文明初始三十六星系保持不可攻占。旧爵位、私人资产、研究和已有战争奖励不清除；已受领的旧战役继续旧流程，原手动档保持独立。

新战争仍在效忠文明核心站受领，核查指挥资格、爵位、航路、未完成借船和唯一活动战役。援军和物资在战区集结；此阶段不声称已有真实跨门舰队行军。各步骤都提供实际玩家操作、明确结果和保存恢复。

## 战争阶段

1. **侦察**：实际抵达目标边疆的侦察点，付费调查；现有扫描强度与环境规则参与工作。未完成侦察不能推进，离开操作范围暂停已付费工作。
2. **护送补给**：核心站普通自有材料进入本次战役托管；运输舰在战区集结，玩家实际护送它通过局部路线。运输舰具有真实HP、碰撞、移动与敌方威胁，可使用现有后勤远修。离开地点不暗中推进物理护送；毁舰或撤退不会复制已支付物资。
3. **两种战斗目标**：按目标定义分为保持登陆范围及至少一艘援军存活到倒计时结束，以及拆除两座真实HP装置。前者考验防护、位置和后勤，后者允许集中打击目标后撤离，不把两种目标都变成清除全部敌舰。补给成功交接后运输舰撤离，援军按现有舰队间距在实际护送位置集结。
4. **占后重建**：实际把普通结构料带到占领点，开始一次已支付修复工作；离开范围暂停、重开保留剩余工作。完成重建后正式登记主权、发放一次奖励并启用当地收益。重建期间继续有明确战役归属和退出操作，不显示成已经稳定统治。

战役援军继续现有推进、集结、集火、撤退指令。准备及重建不能被旧的“无存活友军/守军全灭”判定错误结束；兼容层保留旧war_campaign状态形状，新增阶段状态决定新规则的推进。旧战役只在精确ID/尝试次数匹配时走旧流程。

## 占领与后续争夺

占领首先带来当地真实维修/工业服务改善、阶段性需求和后续合同；不提供私人永久伤害叠加。派生收益由主权和当前效忠实时核查，并进入实际费用/工期消费者。

补给压力体现为扩张和危机的实际材料需求，避免无操作意义的持续日租。多处控制增加整备需求，允许在当地实际交付，以及从所属核心站派出有成本、有到达时间的战略补给；后台运输须明确为粗粒度NPC补给，不能写成已模拟逐舰跨门。

边疆事件按离线世界时间调度，暂停/退出不推进。首轮同一时刻最多一处危机，先预告并给出足够返回/补给时间，再进入可实际防守的战区。防守或补给成功保住主权，失败/放弃后可退回中立；不自动重置个人身份、研究和舰队。初始核心领土及出生航路不进入事件池。

旧占领以有准备窗口的受控状态进入新规则，不能升级后立刻因新补给字段为零而失守。改换效忠保留旧文明成果，当前文明的战争权限和可干预事件分别核验。

首次征服奖励保留已合法取得的历史承诺；重复收复和防守使用有限新奖励定义，不能通过主动失守立刻重复套取首次奖励。胜利、失守和再次收复都保留历史账本。
