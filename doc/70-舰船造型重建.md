# 舰船造型重建

2026-10-14。接续[交互与材质优化](69-交互一致性与材质表现优化.md)。用户明确要求参考 EVE 重做全部舰船造型；范围是当前数值库18种玩家舰体与静默敌舰 `enemy_silent`，共19种视觉。本文记录真实入口、尺寸与签名约束、独立 `ship_v4` 表现包及实际造型/原生预览证据；本轮Windows EXE/PCK已独立验收，具体范围见文末。

## 确认范围与设计依据

重做主轮廓、体块、装甲与结构层级、舰首/舰尾、推进器外壳、舰桥、传感器和用途特征。允许新视觉节点、网格数量与视觉AABB区别于旧模型；新外形保持在原物理包围内，旧碰撞、槽位、挂点、相机和交互锚点不变。数据库、移动/质量/容量/火力数值和存档身份不变。不能用沿用旧轮廓加涂装宣称完成造型重建。

CCP的[Rupture重建过程](https://www.eveonline.com/news/view/iconic-ships-reimagined-the-minmatar-rupture)提出先分析舰体用途与轮廓，再以3D体块迭代处理角度冲突；装甲间的负空间、外露结构和窗列可表达制造逻辑与尺度。[Rubicon美术开发说明](https://www.eveonline.com/news/view/art-for-rubicon-1.1)强调残骸应具有与完整舰体可区分的破损轮廓。本项目采用这些设计方法，结合自身文明与舰种用途创作，原创边界见[11](11-EVE参考与原创边界.md)。

本轮还实际目视CCP官方的 **Abaddon、Astero、Dominix、Raven** 四张舰船图：分别参考连续重甲主壳、弧框与负空间、厚实单主壳体量、不对称构件与舰首/舰尾关系。主整合者先查看2张，另位审查者查看4张，本节补写者也复核了4张；这是唯一4张参考图的交叉复看，不累计成更多独立样本。参考截图曾存于，已按后续清理要求移除，不进入游戏GLB、贴图、缩略图或运行包。网易参考请求被策略阻止，未取得页面或素材，没有绕过限制，也不将其列为已读取/目视的参考。

## 签名依赖与不变结构

- `code/assets/manifest.json` 与 `legacy_art_full_v1/manifest.json`登记基础10个wrapper、models几何、旧GLB与visual_factory；主manifest还登记industrial_visual_factory。旧字节保留。
- `code/assets/civilization_v1/manifest.json`登记文明9个wrapper、hulls、portraits、geometry与civilization_visual_factory。旧字节保留。
- `code/assets/ship_v3/manifest.json`登记旧10个GLB与旧shader。`code/data/local_navigation_v2_manifest.json`、登记station_hangar源码摘要；旧机库不直接改写。
- `code/assets/business_v11/manifest.json`登记既有缩略图；`materials_v1/manifest.json`登记当前surface_style、surface_materials、surface_meshes与material_hangar等；`effects_v1/manifest.json`登记当前FX包。新增舰船适配器复用这些入口，不改其已登记源文件。
- 每个wrapper的 `CharacterBody3D`、CollisionShape3D尺寸/变换、collision_layer=2、collision_mask=3、Hardpoints各槽/索引/muzzle、FXAnchors及相机/交互锚点均沿用。`VisualRoot/Model`的原transform也保留。
- `Hardpoints/weapon_N/muzzle`影响实际发射原点、射界及视线；`Hardpoints/work_N`影响作业束；`FrontCamera`影响前视。新外形围绕原挂点设计，不能为配合造型移动权威挂点。`FXAnchors/engine_left/right`虽保留，当前代码检索没有真实喷焰绑定调用，仅有既有FX构造说明；不能把挂点存在写成已验过所有引擎喷焰。
- 护盾接触半轴在presentation读取原CollisionShape尺寸；不是新视觉AABB。新造型仍在原physics包围内；验收不再要求新旧Mesh逐节点数量或逐Mesh AABB相等。

## 独立v4最小接入

1. 新正式资产：`code/assets/ship_v4/<ID>.glb`覆盖19视觉，`portraits/<ID>.png`随新造型烘焙；新manifest记录来源、轴向、尺寸契约、模型/缩略图摘要与完整清单。生成器与中间文件放jiaoben；旧19个wrapper和旧manifest不动。
2. 新 `code/runtime/rendering/ship_v4_factory.gd`提供现有scene/ship/enemy_scene/enemy及非舰API；直接实例化旧wrapper，仅替换VisualRoot/Model。geometry委托原civilization工厂，保持所有权威尺寸语义；enemy与enemy_scene均读v4，保留原敌舰映射与着色。
3. 新 `code/runtime/rendering/ship_v4_hangar.gd`继承material_hangar，覆盖全18舰展示；保持原showcase长度归一化、HANGAR层、反射剔除和focus_service流程。
4. Sector Factory接新工厂；Main机库preload接新子类；item_portraits优先新缩略图。runtime presentation_resources、export plugin及build_client追加v4 manifest。既有资产身份、catalog与存档冻结定义不变。
5. `SurfaceStyle.apply_ship`继续使用当前幂等材质适配；先着色、后材质适配，避免在ShaderMaterial上失去原敌舰着色。裸预览、机库与真实世界沿同一v4视觉入口。

## 验收底线与当前状态
