# 3D 独立客户端技术栈比较

核验日期：2026-10-02。状态：保留的选型比较资料；用户已选择 Godot 路线。2026-10-03 已安装并运行关键技术探针，当前环境见 [22](22-工具链锁定与技术验证.md)，正式方案见 [技术栈与空间玩法建议](05-技术栈与空间玩法建议.md)。

## 比较目标

- 《星际战舰》采用 3D，包含战舰操作、星区探索、采矿与战斗。
- 最终交付 macOS `.app` 和 Windows `.exe` 桌面客户端，玩家无需打开浏览器。
- 不采用需要收费授权的技术栈；只供自己和朋友玩，不公开发行，不安排付费发行签名与公证。先建立可玩的任务闭环，再扩大内容和规模。
- Unity 保留为 [已记录的备选方案](03-Unity技术栈备选方案.md)。用户已授权按已选定的 Godot 路线文档完成必要开发软件安装。

下表的许可证、平台与工具形态来自官方资料；开发成本、适用方向和推荐次序属于工程判断，未经本项目原型实测。

| Godot 4 + GDScript | 完整 3D 场景编辑器；必要时可用 C# 或原生扩展 | 标准模板直接导出 `.app` / `.exe` | MIT；免费商用，无引擎收入分成，保留许可说明 | 优先候选。安装和导出路径较简单，适合先验证飞行、采矿、战斗闭环；画质、物理和大规模实体仍需测量 |

## 当前推荐

以小团队、AI 协作、本机 Mac 开发、先完成任务闭环及避免引擎费用为前提，优先选择 **Godot 4 + GDScript**；模型工作流需要时配套 Blender。原型阶段先验证一种探索采矿舰、一种战斗舰、一个测试星区和一轮出航返航任务。

按新增的严格免费授权约束，当前主推荐收敛为 Godot，具体镜头、特效和验证方案见 [最新建议](05-技术栈与空间玩法建议.md)。Unity 与 Unreal 在符合条件时可免费起步，但其资格或分成条款使它们不如 Godot 适合本次费用边界，表格保留用于理解备选差异。Bevy 适合愿意承担自建工具成本的 Rust 路线；Web 3D + Electron 适合优先迭代界面和小范围玩法，Panda3D 适合明确偏 Python 的团队。

这些推荐不等于确认性能或联网规模。应以第一版实际画面、帧率、内存与两平台运行结果决定是否扩大舰队和星区规模。

## 构建与运行边界

1. Godot 的纯 GDScript 与标准导出模板可在 Mac 生成两个平台的包；若添加原生扩展或修改引擎，则需提供对应平台二进制。Windows 运行结果仍需在 Windows 验证。[Godot 导出](https://docs.godotengine.org/en/stable/tutorials/export/exporting_projects.html)
2. Unreal 的官方 Windows 打包教程以 Windows 机器为前提。工程上预留 Windows 构建机或 CI，尤其是 C++ 与原生插件项目；不承诺只用当前 Mac 完成全部正式构建。[Unreal 打包](https://dev.epicgames.com/documentation/en-us/unreal-engine/packaging-your-project)
3. Bevy 的 Rust 交叉编译除目标标准库外通常还需要对应链接器与依赖工具链；推荐分平台构建并验证。[Rust 交叉编译](https://rust-lang.github.io/rustup/cross-compilation.html)
4. Electron 可以交叉打包，但原生 Node 依赖与部分打包工具有宿主系统要求；官方 Forge 推荐分平台 CI。[Forge 构建生命周期](https://www.electronforge.io/core-concepts/build-lifecycle)
5. Panda3D 跨平台打包依赖对应平台、架构和 Python 版本的 wheels；不能把输出包视为目标系统已运行通过。[Panda3D 打包](https://docs.panda3d.org/1.10/python/distribution/building-binaries)

macOS `.app` 本身是带目录结构的应用包，Windows `.exe` 也可能带资源和动态库。当前需求是独立客户端，不预设必须单文件。构建时另行确定 macOS Apple Silicon / Intel 和 Windows x64 / ARM64 的支持范围。

当前数据库要求使 Godot 工程需要 SQLite 原生扩展；其平台库与最低 Godot 版本将成为实际构建条件，按 [数据库方案](10-数据库与存读档技术方案.md) 验证。

## Mac 画面与发行

- Unreal 的 macOS 高级功能依赖芯片和版本。查询时官方页面将 M2+ 的硬件光追与 MegaLights 列为 Experimental，Nanite / Virtual Shadow Maps 列为 Beta；选型时应重新核验，不能把 Windows 最高画质直接当作全 Mac 基线。[Unreal macOS 要求](https://dev.epicgames.com/documentation/en-us/unreal-engine/macos-development-requirements-for-unreal-engine)
- Godot 需选择共同渲染基线；Forward+ 与 Compatibility 的效果和硬件覆盖不同，原型要在目标硬件测试。[Godot 渲染器比较](https://docs.godotengine.org/en/stable/tutorials/rendering/renderers.html)
- 当前只做朋友间私下试玩，不安排付费 Developer ID 与公证；Godot 可使用内置 ad-hoc 签名导出。朋友打开下载包时可能仍有系统允许打开的步骤。[Godot macOS 导出](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_macos.html)
