# 全界面工业风审查与整改

2026-10-14。用户要求先逐界面记录问题，再按照记录实施整改。范围为当前 Godot 客户端全部可达界面与子视图；审查轴为色彩、控件一致性、栅格和信息信噪比。

## 标准与边界

用户指定的深灰/黑底、青蓝/琥珀功能色、红色警告是本轮验收标准，不冒称为 EVE 官方色值规范。参考 [EVE Photon 官方说明](https://www.eveonline.com/news/view/photon-ui-iterating-and-improving) 的紧凑界面方向；只借鉴信息组织，不复制品牌资产。借助 awesome-design-md 的 IBM 参考核对平直控件、单层边框和4像素间距尺度，不引入其营销网页布局或品牌蓝。

只修改表现与交互可读性；数值、资格、交易、存档格式和世界规则仍由现有数据库/服务决定。原生截图使用隔离测试库，不能启动个人进度补充验收。

## 统一视觉参数

表现 token 集中在 `code/runtime/ui_theme.gd`：底色 `#101418`、表面 `#171d23`、边线 `#39444d`、正文 `#dce2e5`、次级 `#9ba7af`、青蓝 `#86b8ca`、琥珀 `#c6a76d`、危险 `#db827b`。所有色彩变体从这些语义色派生。按钮/卡片直角、无投影、单层1px边；键盘焦点单独细描边，不能冒充当前选中。

一般布局使用4/8/12/16/24逻辑像素，普通操作高36；仓储30/34、设备槽与HUD等已验证的紧凑几何保留，不机械统一为一个尺寸。名称/说明左对齐，数值右对齐；一般按钮居中，服务导航左对齐。主操作使用琥珀、选择使用琥珀及 pressed/当前文字，负面比较使用琥珀，红色保留给危险操作、敌对或实际故障。
