# 舰船姿态回正与相机基准

v0.8.3；2026-10-03；源码、原生姿态专项与适用回归已通过，实际发布包等待独立验收。完整检查结果、提交与包身份统一登记在 [26](26-开发阶段与交付记录.md)。

## 1. 问题与范围

用户反馈按过A/D后，舰船长期保持倾斜，希望回正观察视角时舰船具有正常姿态。原实现没有单独的转弯侧倾动画：手动及接近/环绕使用局部轴复合旋转，松键后保留旋转结果；跃迁对准沿用舰船现有上轴；跟随视角回正复制舰船完整姿态，可能把残留滚转一起作为相机基准。

本轮修正舰船滚转残留、明确回正时的相机基准，以及带俯仰观察后A/D可能造成的镜头倾斜，保留 [33](33-指令式操舰与运动重影修正.md) 的常驻光标、左键观察、W/S按观察航向推进、A/D左右转弯、总览双击接近与选择/导航/开火分离。没有新增侧倾动画、改变设备数值或重做鼠标操舰。

## 2. 姿态规则

世界坐标的上方向 `Vector3.UP` 是本游戏的视觉与航行基准，属于操作设计，不表示太空存在重力定义的绝对上下。回正只消除围绕舰首方向的滚转；舰首可以继续朝上、朝下或朝任意目标，不把三维航向压成水平飞行。

| 状态或动作 | 已实现的源码行为 |
| --- | --- |
| 普通手动航行 | 先计算本步输入要达到的舰首方向，再构造去除滚转的目标姿态；按照已有转速平滑接近，松键后可继续消除尚未恢复的滚转 |
| Q/E滚转 | 按住时显式滚转输入优先，允许主动倾斜；松开后恢复自动回正，不把最后滚转角锁定为长期姿态 |
| 接近与环绕 | 继续使用真实导航航向、速度、推进能力与距离规则；通过同一个飞行模拟完成滚转恢复 |
| 跃迁准备对准 | 构造朝向目的地的姿态后使用同一个去滚转函数，不沿用旧倾斜作为新的目标上方向；仍受已有转速与对准条件约束 |
| “显示舰船”与V切换 | 跟随视角重置采用去滚转的舰船基准，观察偏移归零；不把残留倾斜复制为默认相机上方向，不瞬移舰船或修改速度 |
| 跟随/战术视角中的A/D | 观察基准和实际镜头同步围绕世界上轴旋转，保留当前观察偏移；不再围绕带俯仰的旧观察上轴累计A/D偏移，避免W+A/D朝旧观察目标拉回 |
| 跟随/战术视角的成像 | 非极点瞄准使用世界上轴的正/负方向，按上一帧镜头右轴选择连续方向；明确重置则按已去滚转的观察右轴选择，保持横轴水平。镜头高度偏移跨过世界垂直线时不会倒置回正后的舰体。极点先投影上一上轴（重置时用观察上轴），退化时投影同一参考右轴，再以非平行全局轴兜底。舰首视角继续跟随实际姿态，不隐藏Q/E主动滚转 |
| 左键自由观察 | 仍是独立相机动作，松开保留观察角度；不因观察自动改写舰船实际姿态或取消已接受导航 |

精确垂直航向没有唯一的世界上方向投影。共用函数在投影退化时保留可用的原横轴，并以其他非平行轴兜底，避免向 `looking_at` 传入平行向量。此边界保证有限、正交姿态，不把垂直舰首强行转回水平，也不承诺穿越垂直极点时存在唯一滚转角。

自由观察和不同镜头的成像会影响舰船在屏幕中的外观。“朝向目标”和“屏幕上完全对称”不是同一条件。本轮同时约束第三人称镜头的水平参考和实际滚转恢复；舰船仍可朝上、朝下或正在转向，不把重置观察当作舰船已经瞬间完成姿态调整。

镜头穿越世界极点时，为保持右轴连续，可能继续采用负世界上方向；直到明确回正时重新按观察基准选向，不承诺所有自由观察始终采用正世界上方向。镜头仍瞄准同一舰船位置，既不改舰首方向，也不改WS实际推进方向的含义。

## 3. 转速、推进与存档边界

飞行模拟将输入旋转与回正合成一个目标四元数，当前姿态只做一次限幅插值，整步旋转不超过真实 `turn_radps × delta`。不在输入旋转之后再额外添加一段不受限的回正，也不引入另一套脚本转速常量。

纯滚转恢复保持舰首前向方向和现有速度，不添加平移；位置仍按原速度与碰撞规则推进。输入推进、原有减速、限速和碰撞仍按真实物理模拟执行；同时转向与回正时共享总转速预算，不承诺每个旋转轴都单独获得完整预算。无效或非正时间步不推进模拟。飞行模拟写回的角速度由本步实际应用的四元数差值计算，包含真实回正动作，不再只记录键盘请求值；跃迁准备继续由导航控制器直接写回实际姿态。

本轮不修改数据库结构、内容定义或存档格式。姿态、速度与角速度仍使用既有typed DTO和SQLite完整快照，继续遵守 [10](10-数据库与存读档技术方案.md) 与 [18](18-进度数据库与存档实现规格.md)。读取已有倾斜存档时先恢复其实际四元数，再在允许的飞行模拟中按相同规则回正；不直接改写存档、不以新资源或JSON另存一套姿态。

停靠、暂停、禁止模拟和事务过渡的既有边界继续生效。回正不成为新手动输入，不取消导航、触发开火、推进世界时间或跳过保存稳定条件。显示层继续使用既有物理插值，实际姿态与相机渲染姿态的职责不变。

姿态专项最终headless **138/138**、Metal/CoreAudio原生 **146/146、5图**通过，日志`jiaoben/logs/attitude-v10-{headless,native}{,-engine}.log`。真实Main键盘、物理与SQLite覆盖带俯仰A/D、W+A/D、Q/E及松键、回正后的屏幕横轴、四组精确/近垂直姿态及离开极点时右轴连续、真实显示舰船、导航保持、实际保存/关闭/重开。原生最终俯仰、旧倾斜回正和极点退出后明确回正画面已查看。测试通过不会瞬间改写个人旧存档；倾斜档案使用独立依法保存的夹具。

适用回归：操控headless280、原生294/2图，导航插值567、雷达/标记69、实际物理战斗18、生命周期27，源码内置发布诊断70项。完整输出及独立引擎日志均退出0，严格错误/警告/泄漏0。字体111文件、84表、858字符，缺字/编码缺陷0。实际Mac发布包须另行通过6项数据库、70项表现与12图；Windows导出不代替原生运行。专项入口和运行隔离见 [脚本目录](../jiaoben/README.md)。

最终验收覆盖以下边界：

- 单次和连续A/D、俯仰后A/D、W+A/D、向上/向下观察后W/S，检查前向航向、滚转收敛、原推力与每步总转速上限。
- Q/E按住能主动滚转，松开后平滑回正；纯回正期间前向与现有速度不变、位置按原速度推进，角速度与真实四元数差值一致。
- 跟随、舰首和战术镜头；倾斜与俯仰起点下重置观察，检查有限正交相机、舰船可见性及回正后的屏幕基准。垂直与近垂直航向不产生NaN或瞬间翻转。
- 接近、环绕、跃迁准备/抵达、手动接管和停止，确认回正不改变导航资格、到达判据、保存稳定屏障或独立开火。
- 独立SQLite存读档检查实际姿态与角速度；菜单、暂停、失焦与退出保存保护继续通过。
- 实际Mac发布包独立运行与画面复查，保留源码专项与实际包证据的区别。Windows导出成功不替代Windows原生运行。

旧检查中的“松开WS后完整Basis立即不再变化”需按新的自动回正规则调整：释放输入不应让舰首继续漂移，但尚未恢复的滚转允许在既有转速预算内收敛。转速、真实输入清零、三维推进、相机独立和SQLite持久化断言继续保留，不能通过删除保护断言获得PASS。
