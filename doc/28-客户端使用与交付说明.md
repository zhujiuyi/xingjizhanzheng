# 客户端使用与交付说明

《星际战舰》当前客户端为离线单人版，包含十星系、九类舰船、三代装备、教学与区域任务、探索采矿、真实飞行战斗、虫洞、市场工业、研究及个人设施。保留联机协议，当前没有同场联机功能。完整功能与验证范围见 [23](23-完整单人版交付范围与实现清单.md) 和 [26](26-开发阶段与交付记录.md)；长期难度和收益需要继续试玩调整。

## 启动

macOS包解压后打开 `mac/星际战舰.app`，无需安装Godot、Blender或数据库服务。构建使用本机临时签名，无付费开发者证书或公证。若朋友从网上下载的副本被macOS拦截，在系统“隐私与安全性”中针对该应用选择打开；不要关闭系统安全机制。

Windows包完整解压到同一文件夹，运行 `windows/XingjiZhanjian.exe`。保留旁边的 `.pck` 和SQLite `.dll`，不能只转发exe。该包为x64导出；Windows真实机器运行验证状态见26。

标题页“新建远征”建立独立世界。“继续航行”恢复当前世界最后成功保存或成功读入的端点；“读取存档”可选择已有世界与固定槽。

## 操作

| 操作 | 键位 |
| --- | --- |
| 前后、左右平移 | W/S、A/D |
| 上下平移、舰身滚转 | Space/C、Q/E |
| 舰首转向 | 相对鼠标移动，受舰船转速限制；停止后最多两个物理步结束请求，不按光标位置持续转向 |
| 显示/释放操作光标 | Alt 切换；可点击目标与 HUD，恢复飞行时按 Alt |
| 基础制动、付费推进设备 | X、按住Shift；基础推进不耗电容 |
| 武器射击 | 左键；朝向锥内已选目标可辅助瞄准 |
| 自由观察 | 按住右键移动鼠标；不会改变舰身朝向，松开后视角回正 |
| 跟随/舰首/战术视角 | V；跟随和战术视角可用滚轮缩放 |
| 选择目标、交互 | Tab、F；右侧目标列表也可直接选择 |
| 星图、任务、暂停 | M、J、Esc |
| 快速存档、读取快速槽 | F5、F9 |

站内进入实际 3D 机库，中央展示当前舰船；左侧四位服务 NPC 提供航管、补给、工业和科研入口，点击查看可拉近职业人员。功能页完成任务受理、借还舰船、货物转移、配装、买卖、制造、修理、研究和建设个人设施。飞行HUD提供停止扫描/采矿、舰船状态、目标距离及当前工作进度。新版统一采用深色工业金属、冰蓝导航和琥珀警示；跟随/战术镜头以舰船原点居中，舰首镜头继承当前舰姿。

新版客户端为0.5.0，原数值库与 `art-full-v1` 冻结资源保持原摘要。表现包独立更新，已有0.4单人档可直接继续；数值与进度仍完全由SQLite管理。

开始从锚港教学任务进入：操控→扫描→借铁砧采矿→借游隼战斗→借提灯探索与返航。任务页列目标和交付站点，教学船只能按当前教学合同借用与交还。完成教学后，随航路主线开放星系，扫描异常发现稀有产出；当地物资、科技、市场和敌人强度不同。

接近门入口并制动，选门按F充能；准备时再按F取消。交战、设备未完成周期、入口资格、门质量额度或费用不满足时会显示原因。成功抵达以目的地SQLite提交为准。

## 保存与恢复

所有数值定义和玩家进度由SQLite数据库管理。暂停菜单提供5个手动槽，另有3个自动槽和1个快速槽。任务交付、交易、制造、研发等成功后请求自动保存，定时保存随游戏时间推进。业务成功提示与“已保存”提示分别显示。

交战、在途弹丸、未完成作业和虫洞期间保存等待稳定边界。暂停会冻结模拟；等待保存时须继续航行让相关周期结束，或取消请求。暂停页可选择保存后退出，也可明确放弃未保存进度退出；后者恢复到最后成功端点。

默认进度库位置：

- macOS：`~/Library/Application Support/Godot/app_userdata/星际战舰/database/progress.db`。
- Windows：`%APPDATA%/Godot/app_userdata/星际战舰/database/progress.db`。

复制个人档案前退出客户端，再备份整个 `database` 文件夹。已有库升级前会生成SQLite备份；失败保留旧库。不要删除进度库来解决兼容错误，保留错误日志与原文件以便诊断。游戏关闭时不推进科研、合同或资源计时。

## 开发复现

在已安装22所述锁定工具链的工作区，可执行：

```sh
/usr/local/bin/python3.14 jiaoben/build_client.py --platform all --publish
```

辅助脚本校验正式资源摘要和数值库、导出两个客户端、校验Mac临时签名，并用实际Mac包完成资源、新建、保存、重开和继续航行的固定数据库诊断。临时构建在 `jiaoben/tmp/`，日志在 `jiaoben/logs/`，检查通过的包复制到忽略的 `code/dist/<build-id>/`，包含使用说明、第三方许可、构建身份与SHA256。测试库不替代个人进度。
