## v0.32行军与成长操作

1. 在“文明与声望”选择成长目标，查看“当前 / 目标”及可用途径。“打开服务”进入任务、研究等对应页面；“定位途径”显示星图，“前往”执行普通航行。研究前置未满足时会显示缺少的科技或任务。
2. 登记并完成四类指挥考核后，在所属文明核心站分别领取贡献奖励。每项每文明仅一次；完成认证及补给准备后可受领边疆战争。
3. 受领后，原NPC舰队从文明核心站集结，经真实地点跃迁和航门队列抵达战区。可以同行，也可先行侦察；侦察完成后等待舰队抵达，再衔接护送和作战。
4. 行军途中保留原舰伤损、物资及逐舰过门进度。撤退需要实际返航；只有未交接的物资按规则返还。暂停会冻结行军，稳定点保存可恢复未完成的队列。
5. 交战中无法跃迁时继续飞离追击范围；僚舰可以先撤退。停止射击并不等于已经脱战。

中后期可依次推进文明专属舰研究与制造、分段远征、殖民地跨站建设。占领地区的危机按游戏内时间预告，可使用储备保障、核心站补给或到场防守；暂停和离线不推进。这些入口的正式验收状态见[矩阵](51-单机完善实施与验收矩阵.md)，正常收入与支出证据见[67](67-自然成长经济与失败恢复验证.md)。

## 自有编队与船员

1. 停靠空间站，进入“舰队与借船 → 船员”，招募操舰员并指派到停靠本站的普通自有舰。教学借船和保障舰不能部署为自有僚舰。
2. 在“自有编队”选择闲置舰，查看配装、船况、准备费和拒绝原因后部署。僚舰使用原有装备、弹药和电容；空武器槽不会产生火力。
3. 出航后使用“推进、集结、集火、撤退”。跨地点跃迁或过门前先集合、收回无人机，并保证全队载重、费用和电容满足要求。
4. “归港收回”用于正常管理；“撤退”会先实际脱离，再带着损伤和剩余物资返港。损毁会损失原舰和设备，不能免费换新。

操舰、火控、工程、侦察岗位分别提供转向、散热、维修和扫描作用。经验来自实际贡献；工资按出航世界时间结算，退出游戏不计欠薪。面板显示等级、忠诚、工资、岗位与所在站。受伤后前往标明的空间站治疗或等待恢复；需要重新购舰时，按实际站点库存选择购买地点。

## 维修与侦察无人机

在允许的舰型上安装对应作业机库，从航行左栏“无人机”打开管理。维修机库适用于织桥、远际、明誓与群星；侦察机库适用于提灯、远际、长鸢与群星。具体槽位、数量、消耗和科技要求以配装页及机库面板为准。

维修无人机需要普通维修耗材、电容和热量余量，会接近友舰并检查视线后修复。侦察无人机前往选中局部地点，提供自身探测范围内的情报；失联后只保留带时效的上次位置。“定位上次位置”不会追踪已经离开的目标。

无人机可能被击毁。只在实际回收后恢复可用数量，损失需在站点补充；换区和保存须等待在外实体结束。攻击无人机继续使用攻击、跟随、回收三种指令。

## 启动

macOS包解压后打开 `mac/星际战舰.app`，无需安装Godot、Blender或数据库服务。构建使用本机临时签名，无付费开发者证书或公证。若朋友从网上下载的副本被macOS拦截，在系统“隐私与安全性”中针对该应用选择打开；不要关闭系统安全机制。

Windows包完整解压到同一文件夹，运行 `windows/XingjiZhanjian.exe`。保留旁边的 `.pck` 和SQLite `.dll`，不能只转发exe。该包为x64导出；Windows真实机器运行验证状态见26。

标题页“新建远征”建立独立世界。“继续航行”恢复当前世界最后成功保存或成功读入的端点；“读取存档”可选择已有世界与固定槽。

“前往目标”明确下达自动航行指令：能跃迁时跃迁，否则接近；跨星系时按钮为“前往虫洞”，只飞到当前路线的下一座虫洞门，制动并按F后才穿越，不会自动跨越全部星系。路线检查会考虑解锁、航门启用状态、剩余寿命、总质量预算和当前舰船总质量；无可通行路线时显示具体阻碍。最终跃迁、穿越、停靠仍重新校验距离、速度、交战、设备周期、冷却和费用。

### 附近交互与导航

F 优先操作已选且满足条件的目标，否则选择范围内最近的可用对象。提示会显示实际对象、操作与阻碍原因：例如距离不足、需制动、冷却、权限、舱容或费用不足。若附近只有不满足条件的对象，先按提示靠近或处理条件；F 不会自动飞过去；空间站的“停靠”按钮另行提供自动接近后进站。鼠标点击目标的交互按钮只操作该对象，失败不会改成另一站点或门；执行时会重新检查资格。鼠标悬停目标栏仍可按F，暂停、业务菜单或文本输入时不能执行飞行交互。

选择总览中的当前星系空间站，点“跃迁”，经过充能与按舰船转速对准后到站外停船，仍处于航行状态。左键短击空间站模型或总览行，操作卡显示跃迁、接近、环绕、停靠与停止；双击总览行会下令转向并接近。远处点“停靠”会正常飞行接近并减速，满足距离、速度和交战条件才进入机库；到站外不会强制入站。已知固定地点和已开放敌群地点可远程列出；实际敌舰按近距群展开或本舰探测条件显示，天体只作航向参考。

明确的手动操舰键接管自动航行；普通鼠标移动、左键观察、缩放和单次选择不接管。非跃迁接管保留原有惯性，不强制回正观察镜头；取消跃迁则安全停船。X或停船按钮只停止移动和导航。Z优先停止已有自动开火，查看空间站或其他目标时也能停火；没有自动开火时，Z才对所选合法敌舰启动开火。目标卡开火按钮与“交战”可明确切换开火目标。普通接近、三维环绕可与自动开火并行；跃迁和停靠要求脱离交战。“交战”启动自动接近并设置开火目标；单独开火按钮不改变导航。武器仍检查射程、射界、视线、冷却、电容与热量；卡片显示实际开火目标与待机原因，不保证命中。

本星系跃迁与跨星系虫洞分别操作：跃迁到门附近后仍需满足原入口资格并按F穿越。M打开星图，可点十星系节点查看风险、势力、空间站、资源和实际虫洞连接示意；示意路线不保证通行权限。

接近门入口并制动，选门按F充能；准备时再按F取消，提交阶段不能再取消。交战、设备未完成周期、入口资格、门质量额度或费用不满足时会显示原因。成功抵达以目的地SQLite提交为准。

左键点击雷达回波选择目标。雷达以上方为舰首方向，显示相对本舰平面的方位；回波短线提示明显的相对高低差。− / + 切换范围，普通回波同时受实际探测上限约束。单次选择不会自动接近、攻击或改变正在攻击的对象；菜单、文字输入和窗口失焦时屏蔽操舰输入，鼠标停在HUD上仍可使用飞行快捷键。

选中目标使用单一四角框；目标旁名称采用无描边和阴影的清晰文字与暗底，不绘制第二圈轮廓。目标与舰船之间显示淡白色虚线；目标离开画面或位于镜头后方时，屏幕边缘显示方向标记。普通目标显示实际局部距离；雷达外围的琥珀天体符号和“远景航向”文字表示背景天体方向，不表示进入探测范围。星系内地点采用AU战略距离，近距操舰、采矿、战斗和停靠使用m/km；星球远景只作背景参照，不能登陆、碰撞或按F交互。

### 星系敌群与打捞鉴定

已开放的星系敌群在总览“战斗”或“全部”中以“侦察小队”“掠袭团”“遗构警戒群”等地点显示，附剩余舰数、等级和整群再生状态；锚港普通敌群在完成战斗教学后开放。可选择群地点并跃迁或接近，它是导航信标，不能对它开火。接近群地点的3000米展开范围，或实际敌舰进入本舰探测范围后，总览显示具体敌舰；选中真实敌舰再执行“交战”或开火。

每群两艘成员，全部击毁后才开始600世界秒的整群再生倒计时；只击毁一艘不会补刷。暂停、退出和跨区保存屏障不推进世界时间。教学及专属合同敌人按各自任务管理，不由普通敌群刷新替代；主线指定原有领舰的目标仍要求击毁该领舰，新增护卫不计入。

普通成员击毁后留下自己的残骸。选中残骸并接近100米，在提示满足视线、归属和舱容条件时按F回收；可先取走放得下的货物或包，其余保留在原残骸。取空后残骸消失，群再生不会清掉尚未取走或未鉴定的包。玩家舰毁留下的已有货物直接回收，不额外生成奖励包。

未鉴定包在“仓库与货舱”中作为独立图片列表行显示，轻型、掠袭、重装包分别占50/120/300升、10/30/80千克。它们计入货舱容量、舰船总质量和虫洞质量限制，需要实际装船转站；不同空间站仓库不共享远程库存。

停靠任意具有仓储服务的空间站后，点击“打捞鉴定”，或在仓库/货舱列表点击包的“鉴定战利品”。各站仓储仍须满足站点服务资格；只能鉴定当前船舱或本地站仓库内的包。鉴定消耗包，信用点进入钱包，矿物或设备进入当前站仓库；界面显示实际所得。包的结果在敌舰死亡时已确定，运输、查看和重试不会重新抽取；完整存档提交失败时保留原包与原资产，不能重复领取。

## 保存与恢复

所有数值定义和玩家进度由SQLite数据库管理。暂停菜单提供5个手动槽，另有3个自动槽和1个快速槽。暂停工作台按航行控制、保存与离开、手动槽和已有档案分组；每张档案卡片显示真实槽位、类型、远征名称和UTC保存时间，保存/读取按钮位于卡片内。首页展开存档使用同一布局，高缩放可滚动访问。任务交付、交易、制造、研发等成功后请求自动保存，定时保存随游戏时间推进。业务成功提示与“已保存”提示分别显示。

交战、在途弹丸、未完成作业、虫洞及活动本星系导航期间，普通保存等待稳定边界。本星系跃迁先保存起点；到达或停止后再保存完整姿态与世界，重启恢复最后提交的端点，不续演途中导航。保存后退出或回到首页会先取消导航停船。暂停会冻结模拟；等待保存时须继续航行让相关周期结束，或取消请求。暂停页可选择保存后退出，也可明确放弃未保存进度退出；后者恢复到最后成功端点。

明确请求“保存并退出”或“保存并返回主菜单”后，清理拖动、待选取和持续固定武器输入，关闭自动开火并停止导航；等待期间阻止新的操舰、开火及业务命令。已支付设备周期、已有弹丸和交战计时仍按原规则推进至稳定边界，再保存并离开。可取消保存恢复操作，或明确放弃未保存进度退出；不是丢弃正在完成的周期或直接跳过保存条件。

默认进度库位置：

- macOS：`~/Library/Application Support/Godot/app_userdata/星际战舰/database/progress.db`。
- Windows：`%APPDATA%/Godot/app_userdata/星际战舰/database/progress.db`。

复制个人档案前退出客户端，再备份整个 `database` 文件夹。已有库格式升级前会生成SQLite备份；失败保留旧库。不要删除进度库来解决兼容错误，保留错误日志与原文件以便诊断。游戏关闭时不推进科研、合同或资源计时。常规保存成功后会清理不再引用的历史自动快照，手动槽、恢复点和升级备份端点保留；维护失败不影响刚刚保存的进度，后续保存会重试。

本轮旧世界内容升级先验证既有冻结定义未被改写，并生成独立SQLite备份，再在完整事务中补入敌群和包的定义及状态。新内容和候选世界成功保存后才切换“继续航行”的端点；失败继续使用原档案并显示原因。原手动槽仍保留，升级来源快照受保护，旧快照按其原冻结内容读取；读取同一来源时复用已登记的升级关系，不重复发放资源。此机制的实际旧档与故障验收结果仍以26为准。

## 开发复现

在已安装22所述锁定工具链的工作区，可执行：

```sh
/usr/local/bin/python3.14 jiaoben/build_client.py --platform all --publish
```

辅助脚本校验正式资源摘要和数值库、导出两个客户端、校验Mac临时签名，并用实际Mac包完成固定数据库与表现诊断。此前v0.8.4构建要求实际Mac包通过78项表现检查并输出14张截图，覆盖业务列表图片、列序、真实报价、数量更新及资金不足显示；保留倾斜回正的总转速预算、显式滚转、镜头回正及垂直航向检查；继续覆盖顶部菜单、底部同排、总览高度和真实采矿保存等待/取消。本轮新增任务、敌群、打捞和旧档升级须另行完成相应专项与最终包验收，不能沿用这些旧版计数宣称新版已通过，也不能用源码结果代替发布结果。当前包的结果与身份见26。临时构建在 `jiaoben/tmp/`，日志在 `jiaoben/logs/`，检查通过的包复制到忽略的 `code/dist/<build-id>/`，包含使用说明、第三方许可、构建身份与SHA256。测试库不替代个人进度。
