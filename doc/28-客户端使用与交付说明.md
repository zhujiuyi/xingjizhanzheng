# 客户端使用与交付说明

《星际战舰》当前客户端为离线单人版，包含十星系、九类舰船、三代装备、教学与区域任务、探索采矿、真实飞行战斗、虫洞、市场工业、研究及个人设施。保留联机协议，当前没有同场联机功能。完整功能与验证范围见 [23](23-完整单人版交付范围与实现清单.md) 和 [26](26-开发阶段与交付记录.md)；长期难度和收益需要继续试玩调整。

本文的操作说明已更新为 **v0.8.0 常驻光标与左键拖动方案**，覆盖旧版捕获鼠标、Alt切换、左键射击和右键观察规则。新版实现与验收状态见 [33](33-指令式操舰与运动重影修正.md)，实际交付构建以26为准；v0.7.0已完成的导航、总览、设备栏和星图继续保留。Windows原生运行尚未验收。

## 启动

macOS包解压后打开 `mac/星际战舰.app`，无需安装Godot、Blender或数据库服务。构建使用本机临时签名，无付费开发者证书或公证。若朋友从网上下载的副本被macOS拦截，在系统“隐私与安全性”中针对该应用选择打开；不要关闭系统安全机制。

Windows包完整解压到同一文件夹，运行 `windows/XingjiZhanjian.exe`。保留旁边的 `.pck` 和SQLite `.dll`，不能只转发exe。该包为x64导出；Windows真实机器运行验证状态见26。

标题页“新建远征”建立独立世界。“继续航行”恢复当前世界最后成功保存或成功读入的端点；“读取存档”可选择已有世界与固定槽。

## 操作

| 操作 | 键位 |
| --- | --- |
| 光标与目标选择 | 光标始终可见；左键短击模型、总览或雷达只选择目标，Tab切换目标 |
| 观察与上下航向 | 左键长按拖动镜头，松开保留角度；向上/下观察后按W沿该航向加速；右键禁用 |
| 前后加速、左右转弯 | W/S沿当前观察航向加速/反向加速；A/D左右转弯，受舰船实际转速限制 |
| 上下移动、舰身滚转 | Space/C、Q/E |
| 自动转向并接近 | 双击总览中的实际目标；远景天体仅选择，不执行接近 |
| 基础制动、耗电推进设备 | X停移动与导航，保留独立自动开火；按住Shift使用推进设备，基础推进不耗电容 |
| 武器射击、自动开火 | Ctrl发射固定武器；Z优先停止已有自动开火，无自动开火时才启动对所选敌舰的开火；目标卡按钮可明确切换开火目标，仍遵守射程、射界与能源条件 |
| 交战 | 选中敌舰后点“交战”，明确切换对此目标开火并自动接近；单击选择本身不转火 |
| 跟随/舰首/战术视角 | V；跟随和战术视角可用滚轮缩放 |
| 找回自己的舰船 | 点击底部“显示舰船”，恢复居中跟随、默认观察角度和距离 |
| 选择目标、条件交互 | Tab 选择；F 按当前条件执行附近交互；右侧列表与雷达可直接选择目标 |
| 雷达范围 | 点击局部态势栏的 − / +，切换500米、2公里、6公里 |
| 星图、任务、暂停 | M、J、Esc |
| 快速存档、读取快速槽 | F5、F9 |

站内进入实际 3D 机库，中央展示当前舰船；左侧四位服务 NPC 提供航管、补给、工业和科研入口，点击肖像“查看”可拉近职业人员，“观察舰船”返回总览。右侧服务按钮直接进入业务页，完成任务受理、借还舰船、货物转移、配装、买卖、制造、修理、研究和建设个人设施。

飞行HUD左侧为航行和任务，右侧为总览及选中操作卡，底部为舰况、雷达与真实设备周期。采用中性透明暗底、薄边框、浅灰文字和克制金色；总览支持全部/战斗/导航与距离/名称/类型排序。设备显示实际配装的完整性、启用状态、剩余周期、冷却和消耗；可以开关设备或使用推进，不提前结束已支付周期。跟随/战术镜头以舰船原点居中，舰首镜头继承当前舰姿。客户端内置 Noto Sans CJK SC，界面与机库人员标签使用同一字体，无需另装中文字体。

舰况仪表上方标明当前视角。舰首视角从船头观察，会隐藏外部舰体，界面标注“舰体隐藏”；读取存档会恢复当时选择的视角。看不到自己的船时，按V切换至战术或跟随，或点击“显示舰船”直接回到居中跟随。恢复镜头不会移动舰船或改变航行速度；鼠标悬停HUD时也可以按V，打开菜单或输入文字时不能切换飞行视角。

数值与进度仍完全由SQLite管理；原数值库与正式美术资源保持原摘要，新增界面与导航表现独立管理。旧档能否继续由客户端兼容校验决定；若报错，保留原档与日志，不手动改库。各版本的实际存读档验收记录见26；不要以旧版本结果代替当前包验证。

开始从锚港教学任务进入：操控→扫描→借铁砧采矿→借游隼战斗→借提灯探索与返航。任务页列目标和交付站点，教学船只能按当前教学合同借用与交还。完成教学后，随航路主线开放星系，扫描异常发现稀有产出；当地物资、科技、市场和敌人强度不同。

### 附近交互与导航

F 优先操作已选且满足条件的目标，否则选择范围内最近的可用对象。提示会显示实际对象、操作与阻碍原因：例如距离不足、需制动、冷却、权限、舱容或费用不足。若附近只有不满足条件的对象，先按提示靠近或处理条件；F 不会自动飞过去；空间站的“停靠”按钮另行提供自动接近后进站。鼠标点击目标的交互按钮只操作该对象，失败不会改成另一站点或门；执行时会重新检查资格。鼠标悬停目标栏仍可按F，暂停、业务菜单或文本输入时不能执行飞行交互。

选择总览中的当前星系空间站，点“跃迁”，经过充能与按舰船转速对准后到站外停船，仍处于航行状态。左键短击空间站模型或总览行，操作卡显示跃迁、接近、环绕、停靠与停止；双击总览行会下令转向并接近。远处点“停靠”会正常飞行接近并减速，满足距离、速度和交战条件才进入机库；到站外不会强制入站。已知固定地点可远程列出；敌舰仍限实际探测范围，天体只作航向参考。

明确的手动操舰键接管自动航行；普通鼠标移动、左键观察、缩放和单次选择不接管。非跃迁接管保留原有惯性，不强制回正观察镜头；取消跃迁则安全停船。X或停船按钮只停止移动和导航。Z优先停止已有自动开火，查看空间站或其他目标时也能停火；没有自动开火时，Z才对所选合法敌舰启动开火。目标卡开火按钮与“交战”可明确切换开火目标。普通接近、三维环绕可与自动开火并行；跃迁和停靠要求脱离交战。“交战”启动自动接近并设置开火目标；单独开火按钮不改变导航。武器仍检查射程、射界、视线、冷却、电容与热量；卡片显示实际开火目标与待机原因，不保证命中。

本星系跃迁与跨星系虫洞分别操作：跃迁到门附近后仍需满足原入口资格并按F穿越。M打开星图，可点十星系节点查看风险、势力、空间站、资源和实际虫洞连接示意；示意路线不保证通行权限。

接近门入口并制动，选门按F充能；准备时再按F取消，提交阶段不能再取消。交战、设备未完成周期、入口资格、门质量额度或费用不满足时会显示原因。成功抵达以目的地SQLite提交为准。

左键点击雷达回波选择目标。雷达以上方为舰首方向，显示相对本舰平面的方位；回波短线提示明显的相对高低差。− / + 切换范围，普通回波同时受实际探测上限约束。单次选择不会自动接近、攻击或改变正在攻击的对象；菜单、文字输入和窗口失焦时屏蔽操舰输入，鼠标停在HUD上仍可使用飞行快捷键。

选中目标使用单一四角框；目标旁名称采用无描边和阴影的清晰文字与暗底，不绘制第二圈轮廓。目标与舰船之间显示淡白色虚线；目标离开画面或位于镜头后方时，屏幕边缘显示方向标记。普通目标显示实际局部距离；雷达外围的琥珀天体符号和“远景航向”文字表示背景天体方向，不表示进入探测范围。十星系天体是压缩尺度的远景参照，不能登陆、碰撞或按F交互，也不代表真实天文距离。

### 当前视觉改版边界

本轮加入原创地貌贴图和暗色星云全景，星空按星区旋转天球；它们是远景表现，不提供可到达的恒星或星云。新工业空间站采用分段装甲环、开放桁架、反应堆/服务芯与货运模块；凹入泊位只表示外观，停靠仍按原距离、速度和业务资格进行，可选择自动接近停靠或近距F，不能把视觉开口当作可穿越船坞。

新工业舰船资源已生成九类既有舰船及静默遗构敌舰共10个模型，适配设计保留原碰撞、武器/工作挂点和镜头锚点，不增加新舰种或另一套数值。独立模型契约、主客户端导航与最终包使用各自的验收记录；具体结果见26和31。

## 保存与恢复

所有数值定义和玩家进度由SQLite数据库管理。暂停菜单提供5个手动槽，另有3个自动槽和1个快速槽。暂停工作台按航行控制、保存与离开、手动槽和已有档案分组；每张档案卡片显示真实槽位、类型、远征名称和UTC保存时间，保存/读取按钮位于卡片内。首页展开存档使用同一布局，高缩放可滚动访问。任务交付、交易、制造、研发等成功后请求自动保存，定时保存随游戏时间推进。业务成功提示与“已保存”提示分别显示。

交战、在途弹丸、未完成作业、虫洞及活动本星系导航期间，普通保存等待稳定边界。本星系跃迁先保存起点；到达或停止后再保存完整姿态与世界，重启恢复最后提交的端点，不续演途中导航。保存后退出或回到首页会先取消导航停船。暂停会冻结模拟；等待保存时须继续航行让相关周期结束，或取消请求。暂停页可选择保存后退出，也可明确放弃未保存进度退出；后者恢复到最后成功端点。

明确请求“保存并退出”或“保存并返回主菜单”后，清理拖动、待选取和持续固定武器输入，关闭自动开火并停止导航；等待期间阻止新的操舰、开火及业务命令。已支付设备周期、已有弹丸和交战计时仍按原规则推进至稳定边界，再保存并离开。可取消保存恢复操作，或明确放弃未保存进度退出；不是丢弃正在完成的周期或直接跳过保存条件。

默认进度库位置：

- macOS：`~/Library/Application Support/Godot/app_userdata/星际战舰/database/progress.db`。
- Windows：`%APPDATA%/Godot/app_userdata/星际战舰/database/progress.db`。

复制个人档案前退出客户端，再备份整个 `database` 文件夹。已有库升级前会生成SQLite备份；失败保留旧库。不要删除进度库来解决兼容错误，保留错误日志与原文件以便诊断。游戏关闭时不推进科研、合同或资源计时。

## 开发复现

在已安装22所述锁定工具链的工作区，可执行：

```sh
/usr/local/bin/python3.14 jiaoben/build_client.py --platform all --publish
```

辅助脚本校验正式资源摘要和数值库、导出两个客户端、校验Mac临时签名，并用实际Mac包完成固定数据库与表现诊断。构建要求实际Mac包通过53项表现检查并输出9张截图，不能用源码结果代替发布结果；当前包的结果与身份见26。临时构建在 `jiaoben/tmp/`，日志在 `jiaoben/logs/`，检查通过的包复制到忽略的 `code/dist/<build-id>/`，包含使用说明、第三方许可、构建身份与SHA256。测试库不替代个人进度。
