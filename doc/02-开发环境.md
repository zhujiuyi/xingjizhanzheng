# 开发环境

## 目录约定

- `code/`：游戏工程、运行配置、正式资源。依赖清单和锁文件随工程保存在这里。
- `doc/`：设定、玩法设计、技术方案和决策。先以可编辑 Markdown 编写，按任务需要导出其他格式。
- `jiaoben/`：测试、辅助脚本、临时文件和日志。长期测试放 `tests/`，临时产物放 `tmp/`，日志放 `logs/`。
- 根目录：Git、编辑器和 Agent 配置，以及总入口文件。

## 检查与版本管理

从工作区根目录运行：

```sh
sh jiaoben/check-env.sh
git status --short --branch
```

Git 在工作区根目录管理源码、文档和可重复执行的测试。临时文件、日志、依赖目录、构建缓存和本地环境文件已加入忽略规则。原始环境检查时尚未配置远程；现阶段源码推送 [私有仓库](https://github.com/zhujiuyi/xingjizhanzheng)，执行时核对实际分支与工作区状态，阶段结果见26。

文本使用 UTF-8、LF；GDScript 使用 tab，其它文本默认空格，由根 `.editorconfig` 管理。

## 已确定路线与已安装环境

用户已确定 **Godot 4 标准版 + GDScript + Forward+ + Blender**，交付 3D macOS / Windows 独立客户端。首版先完成单人闭环，保留联机数据与接口。Unity 保留为历史备选；用户已授权后续按路线文档安装必要开发软件。具体操控默认基线见实现契约，手感与画面仍需样例验证。

技术方案见 [Godot 路线](05-技术栈与空间玩法建议.md)，数据库方案见 [数据库与存读档](10-数据库与存读档技术方案.md)。实际安装：Godot 4.7.2 标准版及匹配桌面模板、godot-sqlite v4.9、Blender 4.5.14 LTS。完整路径、摘要与复现记录见 [工具链锁定与技术验证](22-工具链锁定与技术验证.md)。

已验证实际 Godot SQLite 3.51.0 的只读 catalog、写入/回滚/重开/备份；Mac release 包原生运行与 Metal/Forward+ 渲染成功，Windows x64 交叉导出成功但尚无 Windows 原生运行证据。进度迁移/冻结定义由18的独立夹具校验；真实 SaveService、操控/任务/特效仍按21编码验收。

`sh jiaoben/run_godot.sh` 打开 `code/` 编辑器；完整单人主场景已实现，运行与交付方式见28。导入检查采用 `sh jiaoben/run_godot.sh --headless --editor --path code --quit-after 180`，当前版本不采用本机曾触发退出崩溃的立即 `--import --quit` 流程。

运行或导出产生的临时检查文件放在 `jiaoben/`，引擎必须在工程旁生成的缓存由忽略规则处理。
