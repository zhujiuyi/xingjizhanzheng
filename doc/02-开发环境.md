# 开发环境

## 目录约定

- `code/`：游戏工程、运行配置、正式资源。依赖清单和锁文件随工程保存在这里。
- `doc/`：设定、玩法设计、技术方案和决策。先以可编辑 Markdown 编写，按任务需要导出其他格式。
- `jiaoben/`：测试、辅助脚本、临时文件和日志。长期测试放 `tests/`，临时产物放 `tmp/`，日志放 `logs/`。
- 根目录：Git、编辑器和 Agent 配置，以及总入口文件。

## Windows本机构建

2026-10-06在`E:\星际战舰`安装并验证锁定Godot 4.7.2标准版与Windows x64导出模板。引擎目录为`D:\DevTools\Godot\4.7.2`；同目录`_sc_`启用self-contained模式，模板、编辑器配置和缓存均在其`editor_data/`。Python 3.13.7及Git Bash复用本机已有安装，SQLite原生DLL随工程与客户端提供。已有正式GLB资源可直接构建，`.gdignore`排除Blender源目录，本次导出无需安装Blender。

在工作区根目录的PowerShell执行：

```powershell
$env:GODOT_BIN = 'D:/DevTools/Godot/4.7.2/Godot_v4.7.2-stable_win64_console.exe'
$env:PYTHONUTF8 = '1'
$env:PYTHONIOENCODING = 'utf-8'
$env:Path = 'C:\Program Files\Git\bin;' + $env:Path
py jiaoben/build_client.py --platform windows
```

UTF-8模式用于中文路径、资源清单和构建日志。上述命令执行正式资源校验与Windows导出，产物先保留在`jiaoben/tmp/delivery/<build-id>/`；实际包完成数据库、表现及适用专项检查后再复制到`code/dist/`。原生图形检查使用Vulkan/Forward+与WASAPI，验收窗口须有真实输入焦点，不能以headless结果或修改焦点守卫替代。GUI可执行程序在PowerShell直接调用可能异步返回，验收须显式等待进程结束并核对独立输出/引擎日志。最新Windows交付身份、摘要和原生验证见[26](26-开发阶段与交付记录.md)。
